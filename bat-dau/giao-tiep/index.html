Gọi client ↔ server

Trang này trả lời câu hỏi: muốn client hỏi server, server báo client, hay resource khác dùng core thì viết thế nào.

Cần làmDùngChiều
Client hỏi server và chờ kết quảCallbackclient → server → client
Server báo / đẩy dữ liệu cho 1 người, 1 nhóm, cả serverSocket.emitTo / toRoom / broadcastserver → client
Client gửi lên không cần trả lời (gửi nhiều, tần suất cao)Socket.emit + Socket.onClientclient → server
Trạng thái của 1 người / 1 xe mà mọi client cần thấyState bagserver → mọi client
Script client ↔ giao diện ReactNUIclient ↔ web
Resource khác (Lua / JS) dùng coreExportsresource → az_core
⚠️

Server quyết định mọi thứ. Client chỉ gửi yêu cầu (“tôi muốn còng người này”), server tự kiểm khoảng cách, job, ca trực, đồ, tiền… rồi mới làm. Không bao giờ nhận số tiền, số lượng item, toạ độ “đã kiểm” từ client mà tin luôn.

Callback (client → server)

Cách dùng nhiều nhất. Client gọi, server xử lý, trả kết quả về đúng người gọi.

Server: đăng ký

src/server/jobs/vidu/index.js
const Callbacks = require('../../lib/callbacks');
const PlayerManager = require('../../modules/player/PlayerManager');
const Job = require('../../lib/job');
const Geo = require('../../lib/geo');
 
Callbacks.register('vidu:fine', async (src, target, amount) => {
  // 1. kiểm quyền
  const j = Job.check(src, 'police', { onDuty: true });
  if (!j.ok) return { ok: false, message: j.message };
 
  // 2. kiểm dữ liệu client gửi (không tin client)
  target = Number(target);
  amount = Math.floor(Number(amount));
  if (!(amount > 0 && amount <= 50000)) return { ok: false, message: 'Số tiền không hợp lệ' };
  if (Geo.playerDist(src, target) > 3) return { ok: false, message: 'Đứng quá xa' };
 
  // 3. làm
  const t = PlayerManager.get(target);
  if (!t || !t.removeMoney('bank', amount, 'fine')) return { ok: false, message: 'Không đủ tiền' };
  t.notify(`Bạn bị phạt ${amount}$`, 'error');
  return { ok: true, message: 'Đã phạt' };
});

Client: gọi

src/client/jobs/vidu/index.js
const { callServer } = require('../../lib/callbacks');
const { notify } = require('../../lib/notify');
 
const res = await callServer('vidu:fine', targetServerId, 5000);
if (!res) return notify('Máy chủ không phản hồi, thử lại', 'error'); // lỗi / timeout / spam -> null
notify(res.message, res.ok ? 'success' : 'error');
Hàm clientKhi lỗiDùng khi
callServer(name, ...args)trả nullgần như mọi chỗ
triggerServerCallback(name, ...args)ném lỗi (reject)cần biết lý do lỗi (try / catch)
triggerServerCallbackTimeout(ms, name, ...args)ném lỗicallback phải chờ lâu (chờ người khác bấm đồng ý…) — mặc định chỉ chờ 15 giây
  • Tham số đầu của handler luôn là src (server id người gọi), do server tự lấy, client không giả được.
  • Mỗi người bị giới hạn khoảng 25 lần gọi / giây (dư 80). Gọi tên callback không tồn tại → client nhận lỗi unknown_callback.
  • Kết quả đi về qua socket nếu đã kết nối, không thì qua emitNet. Code không cần quan tâm.
  • Quy ước kết quả: ok: true kèm dữ liệu, hoặc ok: false kèm message để client hiện thông báo.

Server → client

Luôn dùng lib Socket (hoặc player.triggerEvent / player.notify), không dùng emitNet(-1, ...) để broadcast. Socket chưa kết nối thì lib tự rơi về emitNet.

const Socket = require('../../lib/socket');
 
Socket.emitTo(src, 'az_core:vidu:open', data);          // 1 người
Socket.emitToMany([1, 5, 9], 'az_core:vidu:ping');      // nhiều người
Socket.toRoom('job:police', 'az_core:vidu:alert', pos);  // mọi người cùng job (room job:<tên job>)
Socket.toRoom('group:admin', 'az_core:vidu:log', msg);   // mọi người cùng nhóm quyền (room group:<nhóm>)
Socket.broadcast('az_core:vidu:weather', 'rain');         // cả server
 
// có sẵn object Player thì dùng luôn
player.triggerEvent('az_core:vidu:open', data);
player.notify('Xong', 'success');

Phía client nhận bằng onNet như bình thường: lib socket client phát lại event socket thành event local nên onNet vẫn chạy.

onNet('az_core:vidu:open', (data) => {
  Nui.send('vidu:open', data);
  SetNuiFocus(true, true);
});

Tên event đặt dạng az_core:<module>:<việc>. Event dùng nhiều nơi thì khai báo trong src/shared/events.js rồi dùng Events.X.

Socket (client → server)

Dùng khi client gửi nhiều, gửi liên tục (báo giáp, báo vị trí…) hoặc giao diện NUI muốn gọi thẳng server.

const Socket = require('../../lib/socket');
 
// whitelist: event nào không đăng ký onClient sẽ bị bỏ qua
Socket.onClient('vidu:report', (src, value) => {
  // giá trị return được gửi lại nếu client dùng Socket.request
  return { ok: true };
});
const Socket = require('../../lib/socket');
 
Socket.emit('vidu:report', 42);                      // không chờ; false = socket chưa kết nối
const r = await Socket.request('vidu:report', 42);   // chờ kết quả; lỗi / chưa kết nối -> reject
⚠️

Socket có thể chưa kết nối (chưa cấu hình az_socket_public_url, mạng lỗi). Việc quan trọng thì dùng callback, vì callback tự rơi về emitNet.

State bag

// server
Player(String(src)).state.set('cuffed', true, true);
Entity(veh).state.set('az:lock', true, true);
// client
const cuffed = Player(GetPlayerServerId(targetPlayer)).state.cuffed;
AddStateBagChangeHandler('downed', null, (bagName, key, value) => { /* ... */ });

Server ↔ server, client ↔ client (cùng phía)

Các module trong core nói chuyện với nhau bằng event local (emit / onEvent) hoặc require thẳng module kia.

const { onEvent } = require('@shared/lifecycle');
const Events = require('@shared/events');
 
onEvent(Events.Local.PlayerLoaded, (src, data) => { /* player vừa vào */ });
onEvent(Events.Local.MoneyChanged, (src, account, oldValue, newValue, reason) => {});

Danh sách đầy đủ: Event.

Resource khác gọi core

Resource ngoài (Lua hoặc JS) không require được code core, chỉ dùng exports và event.

-- callback cho client của resource mình gọi
exports.az_core:RegisterCallback('myres:buy', function(src, itemName)
  local money = exports.az_core:GetMoney(src, 'cash')
  if money < 100 then return { ok = false, message = 'Không đủ tiền' } end
  exports.az_core:RemoveMoney(src, 'cash', 100, 'myres:buy')
  exports.az_core:AddItem(src, itemName, 1)
  return { ok = true }
end)
 
-- lắng nghe core
AddEventHandler('az_core:playerLoaded', function(src, data)
  print(data.charName, data.job.name)
end)
CreateThread(function()
  -- export async trả Promise: Lua trong thread tự chờ
  local res = exports.az_core:TriggerServerCallback('myres:buy', 'water')
  if res and res.ok then
    exports.az_core:Notify('Đã mua', 'success')
  end
 
  local data = exports.az_core:GetPlayerData()
  print(data.accounts.cash, data.metadata.hunger)
end)
 
AddEventHandler('az_core:playerDataUpdated', function(key, value)
  if key == 'accounts' then print('tiền đổi', value.cash) end
end)
const az = exports.az_core;
 
az.RegisterCallback('myres:buy', async (src, itemName) => {
  if (!az.RemoveMoney(src, 'cash', 100, 'myres:buy')) return { ok: false, message: 'Không đủ tiền' };
  az.AddItem(src, itemName, 1);
  return { ok: true };
});
 
on('az_core:moneyChanged', (src, account, oldValue, newValue, reason) => {});

TriggerServerCallback của client chỉ gọi được callback đã đăng ký bằng RegisterCallback (hoặc Callbacks.register trong core). Không có callback server → client (server không “hỏi” client); server cần dữ liệu từ client thì dùng Socket.emitTo + client trả lời bằng callback.

Chọn nhanh

  • Nút bấm trên UI cần server làm gì đó → NUI callback → client callServer → server Callbacks.register.
  • Server cần mở UI cho người chơi → Socket.emitTo → client onNet → Nui.send.
  • Thông báo cho cả ngành → Socket.toRoom('job:<tên job>', ...).
  • Thông tin người / xe mà người khác cần thấy (còng, gục, khoá xe) → state bag.
  • Dữ liệu của chính người chơi (tiền, job, metadata) → đã tự đồng bộ, xem Player.
