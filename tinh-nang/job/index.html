Tính năngJob

Job

Cấu trúc

Mỗi job có 1 thư mục ở mỗi phía:

      • fishing.js
      • index.js
      • roll.js
      • session.js
      • index.js
      • game.js
      • visuals.js
  • Đăng ký job: thêm 1 dòng vào JOBS trong src/server/jobs/index.js và src/client/jobs/index.js.
  • Tính năng lớn trong job thì tách file riêng (roll.js, session.js…), rồi gọi X.setup() trong setup() của index.js.
  • Cấp bậc + lương gốc nằm ở Config.Jobs. Đổi job bằng player.setJob(name, grade).

Khung chung job nhà nước

jobs/gov/ dùng chung cho các job nhà nước có Boss / Reception / Garages trong shared/jobs/<job>.js (police và ambulance đã chuyển sang resource riêng, hiện không job nào dùng). Config được gom ở shared/jobs/gov.js, đọc từ các file shared/jobs/<job>.js.

PhầnFile
Lễ tân (NPC)jobs/gov/desk.jsvào / hết ca, nộp hồ sơ, đăng ký nhập cư (cấp CCCD 1 lần), mở bảng quản lý
Garage xe công vụjobs/gov/desk.jsmỗi người 1 xe; thoát game / rời job thì xe bị thu
Bảng quản lý ngànhserver/jobs/gov/boss.js, web/src/bosmenuquỹ, nhân viên, chức vụ & lương theo giờ, phát lương theo giờ trực, hồ sơ
App GOV (điện thoại)phone/gov.jsngười dân gọi hỗ trợ, người đang trực nhận đơn

Ca trực lưu ở player.onDuty và đổi bằng player.setDuty(on). Ca trực không lưu DB: vào game hoặc đổi job là hết ca. Exports: SetDuty, ToggleDuty, IsOnDuty, Apply, GetBalance, AddFund (job có bảng quản lý trong core), SetJobByIdCard, SetGrades, SetPaycheck, Payroll (cho resource tự giữ bảng quản lý, như mp_police).

Police

Core chỉ lưu job, cấp bậc, ca trực (Config.Jobs.police). shared/jobs/police.js không còn Boss: core không mở bảng quản lý ngành cho police.

Mọi phần còn lại nằm ở resource mp_police: sổ quản lý ngành (quỹ, giờ trực, phát lương, tuyển / đổi cấp / cho thôi việc, hồ sơ), NPC lễ tân (vào / hết ca, nộp hồ sơ, đăng ký nhập cư), garage xe công vụ, còng, kéo, khám người, đưa lên / kéo xuống xe, kiểm tra / giam xe, MDT, tạm giữ, nhà tù, pháp y… mp_police kiểm điều kiện rồi chủ động gọi export của core: ToggleDuty / SetDuty, SetJob / SetJobByIdCard, SetGrades, SetPaycheck, Payroll, AddLicense, RegisterVehicle, SetCuffed. Quỹ Công an cộng từ hoá đơn ref bắt đầu bằng job:police: qua event az_core:phone:billPaid.

Trạng thái bị còng vẫn ở core vì nhiều tính năng core phải chặn người bị còng: module restraint (src/server/modules/restraint, config src/shared/restraint.js). Resource nghề gọi export server SetCuffed(src, on); core đặt state bag cuffed, chặn các lệnh trong Restraint.Block (shop, ngân hàng, điện thoại, garage, câu cá…), chặn kho đồ, và cho khám túi (SearchPlayer) khi đang bị còng hoặc đang gục.

Ambulance

Core chỉ lưu job, cấp bậc (6 cấp, Config.Jobs.ambulance), ca trực. shared/jobs/ambulance.js rỗng: không Boss, lễ tân, garage.

Mọi phần còn lại nằm ở resource mp_ambulance: mô hình chấn thương theo vùng, sinh hiệu, khám / băng / garo / CPR, NLR khoá nút về viện, quầy tiếp nhận NPC, hoá đơn viện phí, sổ quản lý ngành, lễ tân, garage xe cứu thương. mp_ambulance gọi export SetDeathProvider lúc start để nhận toàn bộ việc gục / hồi sinh; core tắt màn gục + phát hiện chết của mình, chỉ giữ cờ isDead dùng chung (đặt qua SetDowned) để kho đồ, điện thoại, radial… vẫn chặn người đang gục. RevivePlayer, txAdmin heal, /revive chuyển thành event az_core:death:reviveRequest cho mp_ambulance xử lý.

Khi mp_ambulance không chạy, modules/death của core tự xử lý như bản cũ: trọng thương → bất tỉnh, bấm G gọi cứu thương (đơn medic trên app GOV, modules/death/distress.js), hết BleedTime giữ E về viện. Core không còn Cấp cứu / Sơ cứu / Chữa trị / trạng thái yếu.

Câu cá

Config ở shared/jobs/fishing.js. Luồng: dùng cần (can_cau_*) → lắp mồi / máy câu → quăng cần (server trừ mồi và quay ra cá ngay lúc quăng) → minigame trên NUI → thắng thì cá treo ở đầu cần → E nhận / Q thả. Cá bán ở NPC thu mua. Có sự kiện Megalodon / Cá voi (lệnh /fishevent). GM chỉnh chống farm (MaxPerHour, MinFightMs, MinQuality, MaxAcFlags…) và giá / tỷ lệ cá ở trang “Câu cá” của az-tool (key fishing, áp dụng ngay).

server/jobs/fishing/roll.js quay cá, session.js phiên câu (chỉ ở RAM), event.js sự kiện
client/jobs/fishing/game.js phiên câu, visuals.js cần + dây + phao của mọi người (state bag fishing), event.js
web/src/jobs/fishingUI lắp đồ, minigame, thẻ kết quả

Thêm tính năng cho job

Server

src/server/jobs/mechanic/repair.js
const Callbacks = require('../../lib/callbacks');
const Cooldown = require('../../lib/cooldown');
const Job = require('../../lib/job');
const { playerDist } = require('../../lib/geo');
const { Feature } = require('@shared/feature');
 
class JobsMechanicRepair extends Feature {
  #cd = null;
 
  constructor() {
    super('jobs:mechanic:repair');
  }
 
  #repair(src, target) {
    const j = Job.check(src, 'mechanic', { onDuty: true });
    if (!j.ok) return { ok: false, message: j.message };
    if (this.#cd.hit(src)) return { ok: false, message: 'Thao tác quá nhanh' };
    if (playerDist(src, target) > 3) return { ok: false, message: 'Đứng gần hơn' };
    // ...
    return { ok: true, message: 'Đã sửa xong' };
  }
 
  setup() {
    this.#cd = Cooldown.create(1500);
    Callbacks.register('mechanic:repair', (src, target) => this.#repair(src, target));
  }
}
 
module.exports = new JobsMechanicRepair();

Gọi setup

src/server/jobs/mechanic/index.js
setup() {
  Repair.setup();
}

Client

Thêm 1 mục radial với target: 'player', job: { mechanic: 0 }, onDuty: true; trong onSelect gọi callServer('mechanic:repair', ctx.serverId) và notify kết quả.

Menu

Thêm id của mục vào Config.Radial.Menus (ô lẻ hoặc options của một nhóm) để chọn vị trí trong menu.

Thêm job nhà nước mới

Tạo shared/jobs/<job>.js có Boss, Reception, Garages, Vehicles (mô tả trường ở shared/jobs/gov.js và server/jobs/gov/), thêm vào GOV_JOBS trong shared/jobs/gov.js, rồi thêm cấp bậc vào Config.Jobs. Lễ tân, garage công vụ và bảng quản lý sẽ tự có.
