Thanh tiến trình

Port từ lib.progressBar / lib.progressCircle của ox_lib, giao diện “xe chạy theo thanh” của GTAGO.

Clientsrc/client/modules/progress/index.js
Serversrc/server/modules/progress/index.js: chỉ đưa prop cầm tay lên state bag
Webweb/src/progress/, âm thanh / ảnh / font ở web/public/progress/

Progress.bar

Hiện thanh tiến trình ngang. Hàm trả về khi chạy xong hoặc khi bị huỷ.

const Progress = require('../../modules/progress');
const ok = await Progress.bar(data);
local ok = exports.az_core:progressBar(data)
  • data: object
    • duration: number (bắt buộc), thời gian chạy tính bằng ms.
    • label?: string
    • useWhileDead?: boolean. Mặc định false: chết / gục thì dừng.
    • allowRagdoll?: boolean. Mặc định false: bị ngã thì dừng.
    • allowCuffed?: boolean. Mặc định false: bị còng thì dừng.
    • allowFalling?: boolean. Mặc định false: đang rơi thì dừng.
    • allowSwimming?: boolean. Mặc định false: đang bơi thì dừng.
    • canCancel?: boolean. Cho bấm X để huỷ (người chơi đổi phím được trong Cài đặt → Phím → “Huỷ thanh tiến trình”).
    • anim?: object
      • dict?: string
      • clip: string
      • flag?: number, mặc định 49
      • blendIn?: number, mặc định 3.0
      • blendOut?: number, mặc định 1.0
      • duration?: number, mặc định -1
      • playbackRate?: number, mặc định 0
      • lockX?, lockY?, lockZ?: boolean
      • scenario?: string. Dùng scenario thay cho dict / clip.
      • playEnter?: boolean, mặc định true
    • prop?: object hoặc mảng tối đa 2 object
      • model: string hoặc number
      • bone?: number, mặc định 60309
      • pos: [x, y, z] hoặc object có x, y, z
      • rot: [x, y, z] hoặc object có x, y, z
      • rotOrder?: number, mặc định 0
    • disable?: object
      • move?: boolean. Khoá đi bộ, chạy, ngồi xổm.
      • sprint?: boolean. Chỉ khoá chạy.
      • car?: boolean. Khoá lái xe và ra khỏi xe.
      • combat?: boolean. Khoá ngắm, bắn, đánh.
      • mouse?: boolean. Khoá xoay camera.

Trả về: Promise<boolean | null>

Giá trịÝ nghĩa
truechạy hết thời gian
falsebị huỷ (X) hoặc bị ngắt (chết, ngã, còng…)
nullkhông chạy được (đang chết, duration sai…)

Ví dụ

const ok = await Progress.bar({
  label: 'Đang sửa xe',
  duration: 5000,
  canCancel: true,
  disable: { move: true, car: true, combat: true },
  anim: { dict: 'mini@repair', clip: 'fixing_a_ped' },
  prop: { model: 'prop_tool_wrench', bone: 57005, pos: [0.14, 0.0, -0.01], rot: [0, 0, 0] },
});
 
if (ok) {
  // sửa xong: gọi server xác nhận
} else {
  notify('Đã huỷ', 'warning');
}

Progress.circle

Giống Progress.bar nhưng hiện vòng tròn. Có thêm 1 tuỳ chọn:

  • position?: 'middle' hoặc 'bottom'
await Progress.circle({ duration: 3000, position: 'bottom', label: 'Đang mở' });
exports.az_core:progressCircle({ duration = 3000, position = 'bottom', label = 'Đang mở' })

Progress.cancel

Huỷ thanh đang chạy (thanh đó sẽ trả về false).

Progress.cancel();                 // Lua: exports.az_core:cancelProgress()

Progress.active

Progress.active();                 // Lua: exports.az_core:progressActive()  -> boolean

Cơ chế

  • Gọi 2 lần liên tiếp thì xếp hàng: cái sau chờ cái trước xong.
  • Đang chạy thì không mở được kho đồ (“Đang bận”).
  • Mỗi frame: khoá phím theo disable và kiểm các điều kiện ngắt.
  • NUI chạy hết thời gian thì gọi callback progress:complete. Nếu NUI không báo, thanh tự kết thúc sau duration + 1.5s.
  • Kết thúc sớm hơn duration được tính là huỷ.

Prop thấy được với mọi người: client gửi Events.ProgressProps → server lọc (tối đa 2 prop, tên model hợp lệ, kẹp giá trị số) → ghi state bag az:progressProps → mọi client tự tạo object local gắn vào tay. Object không networked nên không tốn entity phía server. Xong thì state bag về null và object bị xoá.
