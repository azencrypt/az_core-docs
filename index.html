Giới thiệu

az_core

az_core là core FiveM viết bằng JavaScript. Server và client build bằng webpack, giao diện (NUI) dùng React 19 + TypeScript build bằng Vite. Mọi tính năng cốt lõi của server nằm trong 1 resource: người chơi, kho đồ, garage, chìa khoá xe, điện thoại, ngân hàng, câu cá, giao hàng (logistics), battle pass, gacha, nhiệm vụ, tân thủ, HUD, menu tròn, thanh tiến trình, mắt tương tác (target), vùng (zone)… Các nghề nghiệp chuyên sâu (Công an mp_police, Y tế mp_ambulance, Nông trại az_farm, Lâm trường mp_lumber, Mỏ đá mp_miner, Xe buýt mp_busjob) được tách thành resource Lua riêng chạy trên core.

Người mới: đọc hết mục Bắt đầu trước khi sửa code. Các mục còn lại dùng để tra cứu khi cần.

Không phụ thuộc framework ngoài

Không cần ESX / QBCore / ox_lib / ox_inventory / oxmysql / spawnmanager / chat mặc định. Core tự làm hết, database dùng mysql2 trực tiếp.
