Thư viện (lib)

⚠️
Có sẵn trong lib thì dùng lại, không tự viết lại trong module.

Server

Callbacks

src/server/lib/callbacks.js

const Callbacks = require('../../lib/callbacks');
Callbacks.register(name, handler);
  • name: string, đặt theo dạng module:hanhDong
  • handler: (src, ...args) => any | Promise<any>. Giá trị trả về chính là kết quả callServer nhận được ở client.

Có rate limit theo từng người: gọi quá nhanh thì client nhận null. Quy ước kết quả: ok: true kèm dữ liệu, hoặc ok: false kèm message.

Callbacks.register('license:show', async (src, target, cardId) => {
  return { ok: true, message: 'Đã xuất trình giấy tờ' };
});

DB

src/server/lib/database.js (mysql2)

HàmTrả về
DB.query(sql, params)mảng dòng
DB.single(sql, params)1 dòng hoặc null
DB.scalar(sql, params)1 giá trị
DB.insert(sql, params)insertId
DB.update(sql, params)affectedRows
DB.transaction(async (q) => ...)chạy trong transaction
const row = await DB.single('SELECT char_name FROM az_users WHERE id = ? LIMIT 1', [id]);

Luôn dùng tham số ?, không nối chuỗi SQL.

Commands

src/server/lib/commands.js

Commands.register(name, group, handler, opts?);
  • group: quyền tối thiểu: user (0), mod (1), admin (2), superadmin (3)
  • handler: (ctx) => any. ctx gồm src, player, args, raw, reply(msg)
  • opts?: help, params (mảng có name, help), allowConsole (mặc định true)
Commands.register('revive', 'admin', ({ args, reply }) => {
  reply('Đã hồi sinh');
}, { help: 'Hồi sinh', params: [{ name: 'id', help: 'ID người chơi' }] });

Socket

src/server/lib/socket.js

Hàm
emitTo(src, event, ...args)gửi 1 người
emitToMany(srcs, event, ...args)gửi nhiều người
broadcast(event, ...args)gửi tất cả
toRoom(room, event, ...args)gửi 1 room (ví dụ job:police)
join(src, room) / leave(src, room)vào / rời room
onClient(event, handler)nhận event client gửi lên qua socket (whitelist)
emitAdmin / onAdminnamespace /admin

Cooldown

src/server/lib/cooldown.js

const cd = Cooldown.create(1500);
if (cd.hit(src)) return fail('Thao tác quá nhanh');
hit(key)còn trong thời gian chờ thì trả true; hết chờ thì ghi mốc mới và trả false
left(key)số ms còn phải chờ
touch(key)ghi mốc (dùng khi muốn tách bước kiểm và bước ghi)

Người chơi thoát thì key của họ tự bị xoá (tắt bằng clearOnDrop: false).

Geo

src/server/lib/geo.js

pedCoords(src)toạ độ + heading của ped, hoặc null
playerDist(a, b)khoảng cách (mét) giữa 2 người chơi; khác bucket / không có ped thì Infinity
entityCoords(ent)toạ độ entity hoặc null
entityDist(a, b)khoảng cách giữa 2 entity
dist3(a, b) / dist2(a, b)khoảng cách giữa 2 điểm

Job

src/server/lib/job.js

const j = Job.check(src, 'police', { onDuty: true, grade: 2 });
if (!j.ok) return { ok: false, message: j.message };
// j.player = Player
Job.is(src, ['police', 'ambulance']); // boolean

RateLimit

RateLimit.create({ burst, perSec, label }) → allow(key), clear(key) (token bucket).

Logger

Logger.info / warn / error / debug, dùng mã màu ^1 ^2 ^7 trên console server.

Payout (payout.js)

giveMoney(player, account, amount, reason, note, idCard?) và takeMoney(player, account, amount, reason, note) (src/server/lib/payout.js): cộng / trừ tiền chuẩn hoá. Nếu account === 'bank', tự động gọi logBank ghi sổ + gửi SMS GO Bank; nếu người nhận đang offline (hoặc đang unload), giveMoney tự xếp hàng queueCredit để trả khi vào lại.

Guard & Service

  • src/server/lib/guard.js: Guard.add(fn) / Guard.blocked(src, name) — hook kiểm tra điều kiện chặn hành động dùng chung (ví dụ bị còng).
  • src/server/lib/service.js: alias trỏ về Feature (@shared/feature).

API & RemoteConfig & Window

  • src/server/lib/api.js: quản lý vòng đời tiến trình az-api, bridge WebSocket, phát/thu hồi token phiên và push realtime (chi tiết: az-api).
  • src/server/lib/remoteConfig.js: register(name, defaults, apply, validate?) — đăng ký cấu hình động lưu ở az_config và sửa từ az-tool.
  • src/server/lib/window.js: canOpenWindow, openWindow, killTree, quote — bật / tắt cửa sổ cmd phụ cho tiến trình az-api trên Windows.

VehicleSpawn (server)

src/server/lib/vehicleSpawn.js: spawnVehicle(model, coords, options) và registerVehicle(entity, options) — wrapper của VehicleManager để tạo xe từ server, đặt biển, bucket và gắn chìa tự động.

Client

callServer

src/client/lib/callbacks.js

const { callServer, triggerServerCallback } = require('../../lib/callbacks');
const res = await callServer('gov:desk', 0, 'duty');   // lỗi / timeout -> null
const data = await triggerServerCallback('az_core:getPlayerData'); // lỗi -> reject
Luôn xử lý trường hợp res === null, ví dụ báo “Máy chủ không phản hồi, thử lại”.

notify

src/client/lib/notify.js

notify(message, type?, length?, title?);
itemNotify({ label, count, image, rarity });
  • type: info, success, error, warning
  • message hỗ trợ mã màu GTA ~r~ ~g~ ~b~ ~y~ ~o~ ~p~ ~w~ ~s~ ~h~; xuống dòng bằng ~br~

Phía server dùng player.notify(...) hoặc export Notify(src, ...).

Nui

src/client/lib/nui.js

Nui.send(action, data)gửi message cho web
Nui.nuiCallback(name, fn, opts?)web gọi fetchNui(name); giá trị fn trả về được gửi lại cho web (undefined thì gửi ok: true)
Nui.onReady(fn)chạy mỗi lần NUI load / reload, nhận cờ reload
Nui.isReady()

Không gọi RegisterNuiCallbackType / SendNUIMessage trực tiếp trong module.

Khác

  • Socket.emit(event, ...) / await Socket.request(event, ...) (client/lib/socket.js)
  • getProps(veh) / setProps(veh, props) (client/lib/vehicleProps.js, định dạng giống ESX)
  • drawText3D(x, y, z, text, { scale?, color?, font?, outline?, shadow?, middle? }) (client/lib/text3d.js): vẽ chữ tại toạ độ thế giới, gọi mỗi frame trong tick. Font mặc định fontId() (az_font), middle căn giữa theo chiều dọc. Chữ viết không dấu. FiveM giới hạn SetDrawOrigin 32 lần / frame.
  • client/lib/api.js: nhận thông tin phiên az-api từ server, chuyển xuống NUI và phát az_core:apiAuth.
  • client/lib/arms.js: fitArms(ped) / armsForTop(ped) — tra bảng shared/data/arms.json để đổi tay (component 3) khớp với áo (component 11) đang mặc, tránh lòi thịt.
  • client/lib/flycam.js: flyCam(shot, focus), stopFlyCam(instant), isFlying() — điều khiển camera bay mượt dùng cho nhiệm vụ tân thủ và preview.
  • client/lib/font.js: fontId(), FONT_NAME, fontText(text) — đọc font BarlowCondensed từ resource az_font.
  • client/lib/vehicleSpawn.js: loadVehicleModel, createLoadedVehicle, spawnVehicle, checkParkedGround, prepareNetworkVehicle — helper tải model, đặt xe trên mặt đất và đợi quyền sở hữu network entity.
