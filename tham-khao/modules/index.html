Danh sách module

Ký hiệu: S = src/server/..., C = src/client/..., W = web/src/.... Callback / event chi tiết xem trong code từng file (tìm Callbacks.register / onNet / Socket.onClient).

Lõi

ModuleLàm gìFile
connectionkiểm identifier, ban, DB trước khi cho vào serverS modules/connection
playerload / save / autosave, đồng bộ vị trí, trả lươngS modules/player · C modules/playerData, position
commandslệnh mặc định của core (admin)S modules/commands · C modules/admin, teleport
socketcấp token, room theo job / group, namespace adminS modules/socket, lib/socket.js · W socket.ts
charactertạo nhân vật (bucket riêng, server kiểm ngoại hình)S modules/character · C modules/creator, appearance
spawnspawn do core quản lýC modules/spawn
gametắt / bật tính năng gốc của GTA (Config.Game)C modules/game
