Nội bộ corePlayer (class)

Player

Dữ liệu người chơi: server giữ bản gốc (Player), client giữ bản sao chỉ đọc (PlayerData). Mọi thay đổi đi từ server xuống.

Vòng đời

  1. Client sẵn sàng → gửi az_core:server:playerReady.
  2. Server PlayerManager.load(src): tìm az_users theo identifier (Config.IdentifierType, mặc định license), chưa có thì tạo dòng mới với Config.StartingAccounts, Config.DefaultJob, Config.DefaultSpawn.
  3. Server gửi PlayerLoaded cho client, bắn event local az_core:playerLoaded (src, data) phía server.
  4. Client nhận, lưu vào PlayerData, bắn az_core:playerLoaded (data) phía client.
  5. Khi đang chơi: server đổi tiền / job / metadata… → player.sync(key) → client nhận PlayerUpdate → bắn az_core:playerDataUpdated (key, value).
  6. Thoát game: az_core:playerUnloading (src, reason) → lưu DB → az_core:playerDropped (src, reason).

Lưu DB: tự động mỗi Config.AutoSaveInterval (5 phút), ngay sau khi tiền đổi (gộp trong 2–5 giây), khi thoát game và khi tắt resource.

Server: Player

Trong core lấy bằng PlayerManager. Resource khác không lấy được object này, dùng exports thay thế.

const PlayerManager = require('../../modules/player/PlayerManager');
 
const player = PlayerManager.get(src);   // null nếu chưa load / đã thoát
if (!player?.hasCharacter()) return;

Tiền

HàmTrả vềGhi chú
getMoney(account = 'cash')numbertài khoản không tồn tại → 0
addMoney(account, amount, reason?)booleanamount phải là số nguyên dương
removeMoney(account, amount, reason?)booleankhông đủ tiền → false, không trừ
setMoney(account, amount, reason?)booleansố nguyên ≥ 0

Mỗi lần đổi: đồng bộ accounts xuống client, bắn az_core:moneyChanged (src, account, oldValue, newValue, reason) và hẹn lưu DB.

if (!player.removeMoney('cash', 500, 'vidu:mua_nuoc')) return { ok: false, message: 'Không đủ tiền mặt' };
⚠️

Luôn ghi reason (dạng module:viec) để sau này tra log tiền. Kiểm kết quả removeMoney rồi mới đưa đồ.

Client: PlayerData

const PlayerData = require('../playerData');      // từ src/client/modules/<module>/
const { onEvent } = require('@shared/lifecycle');
const Events = require('@shared/events');
 
if (PlayerData.isLoaded()) {
  const { job, accounts, metadata } = PlayerData.get();
}
 
onEvent(Events.Local.PlayerLoaded, (data) => { /* vừa vào game */ });
onEvent(Events.Local.PlayerDataUpdated, (key, value) => {
  if (key === 'job') refreshMenu(value);
});
local data = exports.az_core:GetPlayerData()   -- nil nếu chưa load
if exports.az_core:IsPlayerLoaded() then
  print(data.job.name, data.job.onDuty, data.accounts.cash)
end
 
AddEventHandler('az_core:playerLoaded', function(data) end)
AddEventHandler('az_core:playerDataUpdated', function(key, value) end)
⚠️

Dữ liệu client chỉ để hiển thị (HUD, ẩn / hiện menu). Muốn đổi gì phải gọi server; server kiểm lại bằng dữ liệu của server.

Các key có thể nhận trong playerDataUpdated: accounts, job, group, metadata, appearance, charName, charDob.
