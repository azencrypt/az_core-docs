Bạn bè — Server

Kết bạn / huỷ bạn giữa 2 nhân vật, lưu DB (bảng az_friends, az_friend_requests). Resource khác (vd az_farm: chỉ bạn bè mới được ghé farm) gọi export để đọc danh sách và thao tác. Core có sẵn mục radial G “Kết bạn” khi nhìn người chơi.

ExportTrả về
GetFriendsPromise → { idCard, name, online, src, since }[]
AreFriendsPromise → boolean
CountFriendsPromise → number
GetFriendRequestsPromise → { incoming, outgoing }
SendFriendRequestPromise → { ok, accepted?, error? }
AcceptFriendRequestPromise → { ok, accepted?, error? }
DeclineFriendRequestPromise → { ok, error? }
CancelFriendRequestPromise → { ok, error? }
RemoveFriendPromise → { ok, error? }

Quy ước

  • Định danh = idCard = id nhân vật (exports.az_core:GetPlayer(src).id, cột az_users.id), cùng số mà CreateBill, az_farm dùng. Truyền số hoặc chuỗi số đều được (101 / '101').
  • Mọi export server trả Promise (đọc DB khi người đó offline). Lua: gọi trong thread / event handler / callback, tự chờ. JS: await.
  • Đọc (GetFriends, AreFriends, CountFriends, GetFriendRequests) dùng được cả khi người đó offline. Người online có cache trong RAM nên AreFriends gần như không tốn DB.
  • Sửa (SendFriendRequest, Accept, Decline, Cancel, RemoveFriend) nhận src của người làm thao tác (server id), người còn lại là idCard (có thể offline). Resource gọi export phải tự kiểm người chơi được phép làm (ví dụ đúng người bấm nút trong UI của mình); core kiểm phần còn lại.
  • Lời mời lưu DB (người nhận offline vẫn nhận), hết hạn sau RequestTtlHours giờ (mặc định 72). Đã hết hạn thì coi như không có, mời lại được.
  • Chống spam: mỗi người chỉ 1 thao tác sửa mỗi Cooldown ms (mặc định 1500), nhanh hơn trả too_fast.
  • Thông báo (Notify tiếng Việt) core tự gửi: lời mời mới (cả 2 bên), đồng ý (cả 2 bên). Từ chối / rút lời mời / huỷ bạn không báo người kia.
  • Config src/shared/friends.js: Enabled, MaxFriends (100), RequestTtlHours (72), RadialDistance (2.5), Cooldown (1500). Enabled = false chỉ chặn thao tác sửa (lỗi disabled) và ẩn mục radial; đọc danh sách vẫn chạy.

Mã lỗi

MãNghĩa
not_loadedsrc chưa load / chưa vào nhân vật
selfidCard là chính mình
not_foundidCard không tồn tại (không có trong az_users) hoặc sai kiểu
already_friendsđã là bạn
already_sentmình đã mời người này, lời mời còn hạn
not_requestedkhông có lời mời (hoặc đã hết hạn) để đồng ý / từ chối / rút

Radial G “Kết bạn” của core còn có too_far (đứng xa hơn RadialDistance + 1 m), export không trả mã này.

Event

EventPhíaTham sốKhi nào
az_core:friendRequestserver (local)fromIdCard, toIdCardcó lời mời mới
az_core:friendAddedserver (local)a, b (idCard người mời, người đồng ý)2 người thành bạn (đồng ý, hoặc mời chéo tự đồng ý)
az_core:friendRemovedserver (local)a, b (idCard người huỷ, người bị huỷ)huỷ bạn
az_core:friendsChangedclient{ friends, incoming, outgoing } (mảng idCard)danh sách của mình đổi (lúc vào game, mời, đồng ý, từ chối, huỷ, lời mời hết hạn)

az_core:friendsChanged đi qua socket (hoặc emitNet khi socket chưa nối) nên resource khác ở client nghe bằng RegisterNetEvent / onNet:

-- server: nghe 2 người thành bạn
AddEventHandler('az_core:friendAdded', function(a, b)
    print(('idCard %s và %s vừa thành bạn'):format(a, b))
end)
 
-- client: UI của mình đang mở danh sách bạn thì tải lại
RegisterNetEvent('az_core:friendsChanged', function(state)
    if uiOpen then TriggerServerEvent('myres:reloadFriends') end
end)

Radial G (có sẵn trong core)

Nhìn người chơi, bấm G: friend_add “Kết bạn” (chưa là bạn, chưa ai mời ai) / friend_accept “Đồng ý kết bạn” (người đó đã mời mình). Đã là bạn hoặc mình đã mời rồi thì không hiện mục nào. Vị trí trong menu: Config.Radial.Menus.player. Client biết idCard của người đang nhìn qua state bag Player(serverId).state.idCard (server đặt lúc load nhân vật); server không tin giá trị này, tự lấy idCard từ server id và kiểm khoảng cách thật.

GetFriends

Danh sách bạn bè. Người online xếp trước, rồi theo tên.

local result = exports.az_core:GetFriends(idCard)
const result = await exports.az_core.GetFriends(idCard)
  • idCard: number | string — id nhân vật cần lấy danh sách (online hay offline đều được)

Trả về: Promise → { idCard, name, online, src, since }[] — name = tên nhân vật (offline thì lấy từ DB), online boolean, src = server id (offline: nil / null), since = lúc thành bạn (unix ms). idCard sai → mảng rỗng

Ví dụ

CreateThread(function()
    local list = exports.az_core:GetFriends(idCard)
    for _, f in ipairs(list) do
        print(f.idCard, f.name, f.online and ('online #' .. f.src) or 'offline', os.date('%d/%m/%Y', math.floor(f.since / 1000)))
    end
end)
const list = await exports.az_core.GetFriends(idCard);
for (const f of list) console.log(f.idCard, f.name, f.online ? `online #${f.src}` : 'offline');

AreFriends

Hai người có phải bạn bè không. Một trong hai online thì lấy cache (nhanh), cả hai offline thì đọc DB. Trùng nhau hoặc idCard sai → false.

local result = exports.az_core:AreFriends(a, b)
const result = await exports.az_core.AreFriends(a, b)
  • a: number | string — idCard người thứ nhất
  • b: number | string — idCard người thứ hai

Trả về: Promise → boolean

Ví dụ

-- az_farm: chỉ bạn bè mới được ghé farm
local me = exports.az_core:GetPlayer(src)
if not exports.az_core:AreFriends(me.id, ownerIdCard) then
    return exports.az_core:Notify(src, 'Chỉ bạn bè mới được ghé trang trại này.', 'error')
end
const me = exports.az_core.GetPlayer(src);
if (!(await exports.az_core.AreFriends(me.id, ownerIdCard))) return;

CountFriends

Số bạn bè hiện có. idCard sai → 0.

local result = exports.az_core:CountFriends(idCard)
const result = await exports.az_core.CountFriends(idCard)
  • idCard: number | string — id nhân vật

Trả về: Promise → number

Ví dụ

local n = exports.az_core:CountFriends(idCard)
print(('%d bạn'):format(n))
const n = await exports.az_core.CountFriends(idCard);

GetFriendRequests

Lời mời còn hạn. incoming = người khác mời mình, outgoing = mình mời người khác. Mỗi phần tử { idCard, name, at } (at = lúc mời, unix ms), mới nhất trước.

local result = exports.az_core:GetFriendRequests(idCard)
const result = await exports.az_core.GetFriendRequests(idCard)
  • idCard: number | string — id nhân vật

Trả về: Promise → { incoming, outgoing }

Ví dụ

local req = exports.az_core:GetFriendRequests(idCard)
for _, r in ipairs(req.incoming) do
    print(('%s (#%d) mời bạn'):format(r.name, r.idCard))
end
print(('đã mời %d người'):format(#req.outgoing))
const { incoming, outgoing } = await exports.az_core.GetFriendRequests(idCard);

SendFriendRequest

Gửi lời mời kết bạn. Người kia đã mời mình trước (lời mời còn hạn) thì tự đồng ý luôn: trả accepted = true, 2 người thành bạn.

local result = exports.az_core:SendFriendRequest(src, targetIdCard)
const result = await exports.az_core.SendFriendRequest(src, targetIdCard)
  • src: number — server id người chơi làm thao tác (phải đã vào nhân vật)
  • targetIdCard: number | string — idCard người được mời (offline vẫn được)

Trả về: Promise → { ok, accepted?, error? } — { ok = true } (đã gửi), { ok = true, accepted = true } (thành bạn luôn), hoặc { ok = false, error }: disabled, not_loaded, too_fast, self, not_found, already_friends, already_sent, limit_me, limit_target, failed

Ví dụ

local r = exports.az_core:SendFriendRequest(src, targetIdCard)
if not r.ok then
    return exports.az_core:Notify(src, 'Không gửi được: ' .. r.error, 'error')
end
if r.accepted then
    print('đã thành bạn luôn')
end
const r = await exports.az_core.SendFriendRequest(src, targetIdCard);
if (!r.ok) return console.log('lỗi', r.error);

AcceptFriendRequest

Đồng ý lời mời. Kiểm lại MaxFriends của cả 2 bên lúc đồng ý.

local result = exports.az_core:AcceptFriendRequest(src, fromIdCard)
const result = await exports.az_core.AcceptFriendRequest(src, fromIdCard)
  • src: number — server id người chơi làm thao tác (phải đã vào nhân vật)
  • fromIdCard: number | string — idCard người đã mời mình

Trả về: Promise → { ok, accepted?, error? } — { ok = true, accepted = true } hoặc { ok = false, error }: disabled, not_loaded, too_fast, self, already_friends, not_requested, limit_me, limit_target, failed

Ví dụ

local r = exports.az_core:AcceptFriendRequest(src, fromIdCard)
if not r.ok then print('lỗi', r.error) end
const r = await exports.az_core.AcceptFriendRequest(src, fromIdCard);

DeclineFriendRequest

Từ chối lời mời (xoá lời mời, không báo người kia).

local result = exports.az_core:DeclineFriendRequest(src, fromIdCard)
const result = await exports.az_core.DeclineFriendRequest(src, fromIdCard)
  • src: number — server id người chơi làm thao tác (phải đã vào nhân vật)
  • fromIdCard: number | string — idCard người đã mời mình

Trả về: Promise → { ok, error? } — { ok = true } hoặc { ok = false, error = '<mã>' } (xem bảng mã lỗi): disabled, not_loaded, too_fast, self, not_requested, failed

Ví dụ

local r = exports.az_core:DeclineFriendRequest(src, fromIdCard)
const r = await exports.az_core.DeclineFriendRequest(src, fromIdCard);

CancelFriendRequest

Rút lại lời mời mình đã gửi.

local result = exports.az_core:CancelFriendRequest(src, toIdCard)
const result = await exports.az_core.CancelFriendRequest(src, toIdCard)
  • src: number — server id người chơi làm thao tác (phải đã vào nhân vật)
  • toIdCard: number | string — idCard người mình đã mời

Trả về: Promise → { ok, error? } — { ok = true } hoặc { ok = false, error = '<mã>' } (xem bảng mã lỗi): disabled, not_loaded, too_fast, self, not_requested, failed

Ví dụ

local r = exports.az_core:CancelFriendRequest(src, toIdCard)
const r = await exports.az_core.CancelFriendRequest(src, toIdCard);

RemoveFriend

Huỷ bạn (cả 2 phía). Không báo người kia; bắn event az_core:friendRemoved.

local result = exports.az_core:RemoveFriend(src, friendIdCard)
const result = await exports.az_core.RemoveFriend(src, friendIdCard)
  • src: number — server id người chơi làm thao tác (phải đã vào nhân vật)
  • friendIdCard: number | string — idCard người bạn cần huỷ

Trả về: Promise → { ok, error? } — { ok = true } hoặc { ok = false, error = '<mã>' } (xem bảng mã lỗi): disabled, not_loaded, too_fast, self, not_friends, failed

Ví dụ

local r = exports.az_core:RemoveFriend(src, friendIdCard)
if r.ok then exports.az_core:Notify(src, 'Đã huỷ kết bạn.', 'info') end
const r = await exports.az_core.RemoveFriend(src, friendIdCard);
