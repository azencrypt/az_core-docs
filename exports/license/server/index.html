GetLicenses

Giấy tờ đang có.

local result = exports.az_core:GetLicenses(target)
const result = await exports.az_core.GetLicenses(target)
  • target: number | string

Trả về: Promise → { type, label, issuedAt }[]

HasLicense

Có giấy tờ không.

local result = exports.az_core:HasLicense(target, type)
const result = await exports.az_core.HasLicense(target, type)
  • target: number | string
  • type: string — vd driver, boat, weapon

Trả về: Promise → boolean

Ví dụ

exports.az_core:RegisterCallback('myres:rentBoat', function(src)
  if not exports.az_core:HasLicense(src, 'boat') then
    return { ok = false, message = 'Cần bằng lái tàu' }
  end
  return { ok = true }
end)
exports.az_core.RegisterCallback('myres:rentBoat', async (src) => {
  if (!(await exports.az_core.HasLicense(src, 'boat'))) return { ok: false, message: 'Cần bằng lái tàu' };
  return { ok: true };
});

AddLicense

Cấp giấy tờ.

local result = exports.az_core:AddLicense(target, type, silent)
const result = await exports.az_core.AddLicense(target, type, silent)
  • target: number | string
  • type: string
  • silent?: boolean — true = không báo người chơi

Trả về: Promise → boolean

local result = exports.az_core:RemoveLicense(target, type, silent)

Dữ liệu ví (CCCD, thẻ…).

local result = exports.az_core:GetWallet(src)

  • src: number — server id người chơi

ShowCard

Xuất trình 1 thẻ cho người khác xem (giống menu G). Người xem thấy thẻ, người đưa thấy HUD “Đang xuất trình”; hai bên tự đóng khi đứng xa nhau hơn Show.Distance + Show.CloseSlack.

local result = exports.az_core:ShowCard(src, target, cardId)
const result = exports.az_core.ShowCard(src, target, cardId)
  • src: number — server id người chơi
  • target: number — người được xem
  • cardId: string

Trả về: { ok, msg }

ShowWallet

Mở toàn bộ ví giấy tờ của target cho src xem (cả mặt sau CCCD, giấy tờ thiếu hiện “Không có”). Không hỏi đồng ý: resource gọi tự hỏi (Ask) và tự ghi nhật ký. Bấm nút thao tác thì phía client của src bắn az_core:licenseInspectAction { id, ref, target }.

local result = exports.az_core:ShowWallet(src, target, opts)
const result = exports.az_core.ShowWallet(src, target, opts)
  • src: number — server id người chơi
  • target: number — chủ giấy tờ
  • opts?: table — { title, sub, note, actions = {{ id, label }}, ref, distance } — actions tối đa 3 nút, ref (≤ 64 ký tự) được trả lại trong event client az_core:licenseInspectAction, distance không vượt Inspect.Distance

Trả về: boolean — false khi sai tham số, một trong hai chưa có nhân vật, hoặc đứng xa hơn giới hạn (đo ped phía server)

Ví dụ

local ok = exports.az_core:ShowWallet(source, target, {
  title = 'GIẤY TỜ CỦA ĐỐI TƯỢNG',
  sub = 'Đã đồng ý xuất trình',
  actions = { { id = 'mdt', label = 'Tra hồ sơ MDT' } },
  ref = tostring(charId),
})
const ok = exports.az_core.ShowWallet(source, target, { title: 'GIẤY TỜ CỦA ĐỐI TƯỢNG', actions: [{ id: 'mdt', label: 'Tra hồ sơ MDT' }], ref: String(charId) });
