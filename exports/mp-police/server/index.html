mp_police (Công an) — Server

Resource Lua mp_police (Công an hard RP): MDT, truy nã / BOLO, tạm giữ, nhà tù, pháp y vật chứng, giam xe & bãi chuộc, còng áp giải và sổ quản lý ngành. Đây không phải export của core: Lua gọi exports.mp_police:Ten(...), JS gọi exports.mp_police.Ten(...).

  • Trong server.cfg, ensure mp_police phải đứng sau ensure az_core.
  • Trạng thái thụ án được đồng bộ qua state bag jailed (chỉ server ghi).
  • Tin báo có giới hạn phụ trách (PoliceAlert kèm slots + ref): mỗi lần danh sách cán bộ phụ trách đổi (nhận, rời vụ, hết ca, bị gục, thoát game, đóng tin), server bắn event mp_police:alertAssign (ref, srcList, alertId) — nghe bằng AddEventHandler phía server.

PoliceAlert

Gửi tin báo điều phối (dispatch) tới tất cả cán bộ Công an đang trực và lưu vào tab tin báo trên MDT.

local result = exports.mp_police:PoliceAlert(data)
const result = exports.mp_police.PoliceAlert(data)
  • data: table — { type, coords = { x, y, z? }, title?, message?, exact?, slots?, ref? }: type thuộc shots (10-71), robbery (10-90), panic (10-99), custom (10-00). exact = true để gửi ngay toạ độ chính xác thay vì làm mờ 60 m + trễ 5–15 s. slots (1–Config.Dispatch.CaseMaxSlots, mặc định tối đa 4) + ref (chuỗi ≤ 64 ký tự, mã vụ của resource gọi): mở tin có giới hạn phụ trách — không gộp với tin khác, ghim trên HUD cán bộ đang trực tới khi CloseAlert(ref) (hoặc hết Config.Dispatch.CaseTtlSec), cán bộ nhận / rời bằng phím F7 hoặc nút trong MDT tab Tin báo. Gọi lại cùng ref không tạo tin mới

Trả về: boolean

Ví dụ

exports.mp_police:PoliceAlert({
  type = 'robbery',
  coords = { x = x, y = y, z = z },
  title = 'Cướp tạp hoá',
  message = '24/7 · Innocence Blvd',
  slots = 2,
  ref = 'mp_groceryrob:' .. robId,
})
exports.mp_police.PoliceAlert({
  type: 'robbery',
  coords: { x, y, z },
  title: 'Cướp tạp hoá',
  message: '24/7 · Innocence Blvd',
  slots: 2,
  ref: `mp_groceryrob:${robId}`,
});

UpdateAlert

Cập nhật phiếu của tin có giới hạn phụ trách (dòng pha, đồng hồ, ô quyền) và đẩy ngay cho cán bộ đang trực. Trả false nếu không có tin mở với ref đó.

local result = exports.mp_police:UpdateAlert(ref, extra)
const result = exports.mp_police.UpdateAlert(ref, extra)
  • ref: string — mã vụ đã truyền vào PoliceAlert
  • extra: table — { line?, endsLabel?, ends?, status?, rule?, note?, tone? }: line = dòng pha (≤ 120 ký tự), ends = mốc Unix (giây) cho đồng hồ, endsLabel = chữ trước đồng hồ, status / rule / note = ô quyền hiện cho cán bộ phụ trách, tone thuộc amber · red · grey · green · navy · ink. Trường sai kiểu / lạ bị bỏ; gọi lại là thay toàn bộ

Trả về: boolean

Ví dụ

exports.mp_police:UpdateAlert(ref, {
  line = 'truy đuổi', endsLabel = 'còn', ends = os.time() + 300,
  status = 'CON TIN ĐANG BỊ GIỮ', rule = 'KHÔNG NỔ SÚNG', note = 'Chỉ bám theo, khống chế cận chiến, ép xe.', tone = 'amber',
})
exports.mp_police.UpdateAlert(ref, { line: 'truy đuổi', endsLabel: 'còn', ends: Math.floor(Date.now() / 1000) + 300, rule: 'KHÔNG NỔ SÚNG', tone: 'amber' });

CloseAlert

Đóng tin có giới hạn phụ trách khi vụ kết thúc: gỡ phiếu ghim + blip ở client, bỏ danh sách phụ trách (bắn mp_police:alertAssign với danh sách rỗng nếu đang có người). Trả false nếu không có tin mở với ref đó.

local result = exports.mp_police:CloseAlert(ref)
const result = exports.mp_police.CloseAlert(ref)
  • ref: string — mã vụ đã truyền vào PoliceAlert

Trả về: boolean

Ví dụ

exports.mp_police:CloseAlert(ref)
exports.mp_police.CloseAlert(ref);

GetAssigned

Server id các cán bộ đang phụ trách vụ (theo thứ tự nhận). Tin không còn → mảng rỗng.

local result = exports.mp_police:GetAssigned(ref)
const result = exports.mp_police.GetAssigned(ref)
  • ref: string — mã vụ đã truyền vào PoliceAlert

Trả về: number[]

Ví dụ

local list = exports.mp_police:GetAssigned(ref)
const list = exports.mp_police.GetAssigned(ref);

HasActiveWarrant

Kiểm tra công dân có lệnh truy nã đang hiệu lực (status = "active") trong bảng mp_police_warrants không.

local result = exports.mp_police:HasActiveWarrant(charId)
const result = exports.mp_police.HasActiveWarrant(charId)
  • charId: number — id nhân vật (az_users.id / GetPlayer(src).id)

Trả về: boolean

Ví dụ

if exports.mp_police:HasActiveWarrant(charId) then print('Đang bị truy nã') end
if (exports.mp_police.HasActiveWarrant(charId)) console.log('Đang bị truy nã');

IsJailed

Kiểm tra người chơi có đang thụ án trong nhà tù không.

local result = exports.mp_police:IsJailed(src)
const result = exports.mp_police.IsJailed(src)
  • src: number — server id người chơi

Trả về: boolean

Ví dụ

if exports.mp_police:IsJailed(src) then return end
if (exports.mp_police.IsJailed(src)) return;

local result = exports.mp_police:GetJailTime(src)
const result = exports.mp_police.GetJailTime(src)
  • src: number — server id người chơi

Trả về: number

Ví dụ

local sec = exports.mp_police:GetJailTime(src)
const sec = exports.mp_police.GetJailTime(src);

SendToJail

Đưa người chơi vào tù: tịch thu đồ (trả lại khi ra tù), chuyển vào trại và ghi nhật ký audit kèm tên resource gọi.

local result = exports.mp_police:SendToJail(src, months, reason)
const result = exports.mp_police.SendToJail(src, months, reason)
  • src: number — server id người chơi
  • months: number — số tháng án (1 tới Config.JailMaxMonths cao nhất)
  • reason?: string — lý do đưa vào tù (tối đa 128 ký tự)

Trả về: boolean — false nếu chưa đặt Config.Jail.Cells, sai số tháng hoặc người chơi chưa vào nhân vật

Ví dụ

exports.mp_police:SendToJail(src, 10, 'Phạm tội quả tang')
exports.mp_police.SendToJail(src, 10, 'Phạm tội quả tang');

ReleaseFromJail

Thả người chơi khỏi tù sớm, trả lại đồ đã tịch thu và ghi audit log.

local result = exports.mp_police:ReleaseFromJail(src, reason)
const result = exports.mp_police.ReleaseFromJail(src, reason)
  • src: number — server id người chơi
  • reason?: string — lý do thả (mặc định "export")

Trả về: boolean

Ví dụ

exports.mp_police:ReleaseFromJail(src, 'duoc_an_xa')
exports.mp_police.ReleaseFromJail(src, 'duoc_an_xa');

AddEvidence

Tạo thêm 1 dấu vết vật chứng trên mặt đất (lưu RAM theo ô lưới, chỉ cán bộ cầm đèn pin mới nhìn thấy và thu được).

local result = exports.mp_police:AddEvidence(type, coords, data)
const result = exports.mp_police.AddEvidence(type, coords, data)
  • type: string — loại vật chứng: casing, impact, blood, vehicle_print
  • coords: table — { x, y, z? }
  • data?: table — bảng phẳng các trường string | number | boolean (key ≤ 24, string ≤ 64 ký tự)

Trả về: number | nil — ID vật chứng trong RAM hoặc nil nếu tham số không hợp lệ

Ví dụ

exports.mp_police:AddEvidence('blood', { x = x, y = y, z = z }, { charId = idCard, cause = 'cut' })
exports.mp_police.AddEvidence('blood', { x, y, z }, { charId: idCard, cause: 'cut' });
