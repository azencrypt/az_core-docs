Kho đồ — Server

Item phải khai báo trong src/shared/items.js. Kho cá nhân gồm phím nhanh (fast, mỗi ô khai báo ở Config.Inventory.FastSlots: nhận gì + cấp mở khoá), túi (pocket), balo (backpack), túi an toàn (safe, tắt được bằng Config.Inventory.SafePocketEnabled) và đồ mặc (equip, chỉ quần áo). Hàm có target nhận src người chơi hoặc id kho (stash, cốp trunk:BIEN, hộc glove:BIEN, drop, kho tạm). Ô đồ luôn là inv + slot (vd pocket ô 3). Đếm / trừ không chỉ ô thì lấy ở túi + balo + phím nhanh, không đụng túi an toàn.

Hook kho đồ

Resource khác gắn hàm vào kho đồ để chặn hoặc sửa hành động mà không cần sửa core. Gắn bằng RegisterHook (trả id), gỡ bằng RemoveHooks. Resource đã gắn mà dừng thì hook của nó tự gỡ.

EventChạy khiHàm trả false thì
swapItemskéo đồ sang ô khác / kho khác, gộp chồng, đổi chỗ, vứt xuống đấthuỷ, người chơi thấy “Không thể làm vậy”
usingItembấm dùng item (sau khi kiểm hết hạn, trước callback dùng item)không dùng, không báo gì (tự Notify nếu cần)
openInventorymở kho phụ: stash, cốp, hộc, drop, kho tạm, ForceOpenInventory… (mở túi mình thôi thì không chạy)không mở, báo “Không mở được kho này”
createItemcore tạo metadata cho item mới (AddItem, rơi đồ, quà…)không chặn được: trả bảng metadata mới để thay, trả gì khác thì giữ nguyên

Payload hàm nhận

  • swapItems: source, action, name, count, fromInventory, fromType, fromSlot, toInventory, toType, toSlot
    • action: move (sang ô trống) · stack (gộp chồng) · swap (đổi chỗ 2 món) · drop (vứt đất)
    • fromSlot: bảng món đang kéo { name, count, slot, metadata }
    • toSlot: move là số ô đích · stack / swap là bảng món ở ô đích · drop là nil (lúc này toInventory = 'ground', toType = 'drop')
  • usingItem: source, name, inventoryId, inventoryType, inv (pocket · backpack…), slot, item (bảng món)
  • openInventory: source, inventoryId, inventoryType, label, forced (true = mở bằng ForceOpenInventory)
  • createItem: name, metadata

Kiểu kho (*Type): pocket · fast · equip · safe · backpack · wardrobe · stash · temp · trunk · glovebox · drop · container · mail. Id kho (*Inventory): pocket:<id nhân vật> · trunk:BIEN · glove:BIEN · id stash đã đăng ký (vd police_stash) · drop:N…

Lọc (options)

Không lọc thì hook chạy cho mọi lần kéo / dùng / mở, nên luôn lọc khi được.

  • itemFilter: chỉ chạy khi name khớp. Nhận { bread = true }, { 'bread', 'water' } hoặc 'bread'.
  • inventoryFilter: regex JS (1 chuỗi hoặc mảng), chạy khi một trong inventoryId / fromInventory / toInventory khớp. Vd { '^trunk:', '^police_' }.
  • typeFilter: như itemFilter nhưng so với inventoryType / fromType / toType. Vd { trunk = true, glovebox = true }.
  • createItem không có id / kiểu kho, nên chỉ lọc được bằng itemFilter.

Ví dụ

-- 1. Cấm vứt súng xuống đất và cấm bỏ súng vào cốp / hộc xe
exports.az_core:RegisterHook('swapItems', function(p)
  if p.action == 'drop' or p.toType == 'trunk' or p.toType == 'glovebox' then
    exports.az_core:Notify(p.source, 'Không được cất / vứt súng', 'error')
    return false
  end
end, { itemFilter = { WEAPON_PISTOL = true, WEAPON_SMG = true } })
 
-- 2. Còng tay chỉ cảnh sát đang trực mới dùng được
exports.az_core:RegisterHook('usingItem', function(p)
  local job = exports.az_core:GetJob(p.source)
  if not (job and job.name == 'police' and job.onDuty) then
    exports.az_core:Notify(p.source, 'Chỉ cảnh sát mới dùng được', 'error')
    return false
  end
end, { itemFilter = { handcuffs = true } })
 
-- 3. Kho police_* chỉ người job police mở được (trừ khi core / admin ép mở)
exports.az_core:RegisterHook('openInventory', function(p)
  if p.forced then return end
  local job = exports.az_core:GetJob(p.source)
  return job ~= nil and job.name == 'police'
end, { inventoryFilter = '^police_' })
 
-- 4. Gắn thêm metadata khi tạo item
exports.az_core:RegisterHook('createItem', function(p)
  local m = p.metadata
  m.batch = m.batch or os.date('%Y%m%d')
  return m
end, { itemFilter = { bread = true, water = true } })
 
-- Gỡ 1 hook theo id, hoặc gỡ hết hook của resource này
local id = exports.az_core:RegisterHook('usingItem', function(p) end, { itemFilter = 'bread' })
exports.az_core:RemoveHooks(id)
exports.az_core:RemoveHooks()
exports.az_core.RegisterHook('swapItems', (p) => {
  if (p.action === 'drop' || p.toType === 'trunk' || p.toType === 'glovebox') {
    exports.az_core.Notify(p.source, 'Không được cất / vứt súng', 'error');
    return false;
  }
}, { itemFilter: ['WEAPON_PISTOL', 'WEAPON_SMG'] });
 
exports.az_core.RegisterHook('openInventory', async (p) => {
  if (p.forced) return;
  const job = exports.az_core.GetJob(p.source);
  return job?.name === 'police';
}, { inventoryFilter: '^police_' });
 
exports.az_core.RegisterHook('createItem', (p) => ({ ...p.metadata, batch: p.metadata.batch ?? Date.now() }), { itemFilter: ['bread', 'water'] });
⚠️
  • Chỉ trả đúng false mới chặn. Trả nil / true / không trả gì là cho qua.
  • Nhiều hook cùng event chạy theo thứ tự gắn, gặp hook trả false là dừng luôn.
  • Hook bị lỗi thì core ghi log rồi bỏ qua (không chặn).
  • payload là bản sao: sửa trong hook không đổi gì kho. Muốn đổi metadata khi tạo item thì trả bảng ở createItem.
  • createItem chạy đồng bộ: hàm JS async / Promise bị bỏ qua. Hàm Lua của mọi event nên trả kết quả ngay, không Wait.

AddItem

Thêm đồ. Người chơi: chỉ vào túi (pocket), không tự vào balo (muốn cất balo thì người chơi tự kéo); túi đầy thì trả false. Kho khác: vào kho đó (stash lưu DB ngay). Có opts.slot hoặc target là kho thì trả Promise.

local result = exports.az_core:AddItem(target, name, count, metadata, opts)
const result = exports.az_core.AddItem(target, name, count, metadata, opts)
  • target: number | string | table — src người chơi, hoặc id kho: stash đã đăng ký · trunk:BIEN · glove:BIEN · drop:N · temp:N · { id, owner } cho stash riêng từng người
  • name: string
  • count?: number — mặc định 1
  • metadata?: table
  • opts?: table — quiet = không hiện thông báo nhận đồ · fresh (mặc định true) = tính lại hạn dùng từ lúc nhận · slot (+ inv) = bỏ vào đúng ô, ô không hợp lệ thì vào ô trống đầu tiên

Trả về: boolean — false = không chứa được

Ví dụ

if not exports.az_core:AddItem(source, 'water', 2, { quality = 100 }) then
  exports.az_core:Notify(source, 'Túi đầy', 'error')
end
if (!exports.az_core.AddItem(source, 'water', 2, { quality: 100 })) {
  exports.az_core.Notify(source, 'Túi đầy', 'error');
}

RegisterUsableItem

Xử lý khi người chơi bấm Dùng item (chỉ trong kho cá nhân).

local result = exports.az_core:RegisterUsableItem(name, cb)
const result = exports.az_core.RegisterUsableItem(name, cb)
  • name: string
  • cb: function(source, item, inv) — item: name, count, slot, metadata. Trả false = không dùng được (không trừ đồ)

Trả về: boolean

Ví dụ

exports.az_core:RegisterUsableItem('myres_box', function(source, item, inv)
  if not exports.az_core:CanCarryItem(source, 'bread', 3) then
    exports.az_core:Notify(source, 'Túi đầy', 'error')
    return false
  end
  exports.az_core:RemoveItem(source, 'myres_box', 1)
  exports.az_core:AddItem(source, 'bread', 3)
  return true
end)
exports.az_core.RegisterUsableItem('myres_box', (source, item, inv) => {
  if (!exports.az_core.CanCarryItem(source, 'bread', 3)) {
    exports.az_core.Notify(source, 'Túi đầy', 'error');
    return false;
  }
  exports.az_core.RemoveItem(source, 'myres_box', 1);
  exports.az_core.AddItem(source, 'bread', 3);
  return true;
});

  • count?: number
  • metadata?: table

Trả về: Promise → { ok, reason? }

Ví dụ

CreateThread(function()
  local r = exports.az_core:SendToMail(charId, 'water', 5, { from = 'Sự kiện' })
  if not r.ok then print(r.reason) end
end)
const r = await exports.az_core.SendToMail(charId, 'water', 5, { from: 'Sự kiện' });
if (!r.ok) console.log(r.reason);
