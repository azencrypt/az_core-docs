Callback & lệnh — Client

Gọi callback đã đăng ký ở server (bằng RegisterCallback). Chờ tối đa 15 giây. SendNui / RegisterNuiCallback / SetNuiFocus dùng khi giao diện của resource vẽ trong khung NUI của az_core.

Hướng dẫn chi tiết: Gọi client ↔ server.

ExportTrả về
TriggerServerCallbackPromise → any
SendNui
RegisterNuiCallbackboolean
SetNuiFocusboolean

TriggerServerCallback

Gọi callback server, chờ kết quả.

local result = exports.az_core:TriggerServerCallback(name, ...args)
const result = await exports.az_core.TriggerServerCallback(name, ...args)
  • name: string
  • …args: any — dữ liệu gửi lên — server phải kiểm lại

Trả về: Promise → any — giá trị handler server trả. Lỗi / quá 15 giây / tên không tồn tại → lỗi (reject)

Ví dụ

CreateThread(function()
  local ok, res = pcall(function()
    return exports.az_core:TriggerServerCallback('myres:buy', 'water', 2)
  end)
  if not ok or not res then return exports.az_core:Notify('Máy chủ không phản hồi', 'error') end
  if not res.ok then return exports.az_core:Notify(res.message, 'error') end
  exports.az_core:Notify('Đã mua', 'success')
end)
try {
  const res = await exports.az_core.TriggerServerCallback('myres:buy', 'water', 2);
  if (!res.ok) return exports.az_core.Notify(res.message, 'error');
  exports.az_core.Notify('Đã mua', 'success');
} catch {
  exports.az_core.Notify('Máy chủ không phản hồi', 'error');
}

SendNui

Gửi message vào khung NUI của az_core. Dùng khi giao diện của resource được viết sẵn trong az_core/web (vd shop của az_shop): resource đó không cần ui_page, nên thông báo, HUD của core vẫn hiện trên cùng, không bị khung khác đè.

exports.az_core:SendNui(action, data)
exports.az_core.SendNui(action, data)
  • action: string — tên message, React nghe bằng useNuiEvent(action)
  • data?: any

Ví dụ

exports.az_core:SendNui('shop:open', shopData)

RegisterNuiCallback

Nhận callback NUI từ khung az_core thay cho RegisterNUICallback của resource mình. Đăng ký lại cùng tên thì thay handler. Resource dừng thì callback trả { ok = false } tới khi đăng ký lại. az_core chạy lại thì phải đăng ký lại.

local result = exports.az_core:RegisterNuiCallback(name, handler)
const result = exports.az_core.RegisterNuiCallback(name, handler)
  • name: string — tên fetchNui(name) gọi từ khung az_core
  • handler: function — nhận data, trả bảng kết quả cho NUI (được async). Trả nil = { ok = true }

Trả về: boolean — false khi tên trống, handler không phải hàm, hoặc tên trùng callback có sẵn của core

Ví dụ

exports.az_core:RegisterNuiCallback('shop:buy', function(data)
  return { ok = true }
end)
exports.az_core.RegisterNuiCallback('shop:buy', async (data) => {
  const res = await exports.az_core.TriggerServerCallback('shop:buy', data.item, data.qty);
  return res ?? { ok: false };
});

SetNuiFocus

Bật / tắt focus chuột + bàn phím cho khung az_core (dùng thay SetNuiFocus native khi giao diện nằm trong az_core). Resource gọi bật focus mà dừng thì core tự nhả focus.

local result = exports.az_core:SetNuiFocus(focus, cursor)
const result = exports.az_core.SetNuiFocus(focus, cursor)
  • focus: boolean
  • cursor: boolean

Trả về: boolean

Ví dụ

exports.az_core:SetNuiFocus(true, true)
