az_farm (trang trại) — Server

Resource Lua az_farm (trang trại): kho nông sản riêng, cấp nghề, ô đất, farm riêng từng người (routing bucket), trang trí, trồng trọt, máy chế biến, quầy hàng bán cho bạn bè, ghé thăm farm bạn bè, prop tương tác (bấm G). Bạn bè nằm ở az_core (exports nhóm Bạn bè). Đây không phải export của core: Lua gọi exports.az_farm:Ten(...), JS gọi exports.az_farm.Ten(...). Mọi export đều ở server, az_farm không có export client. Danh sách lệnh chat / lệnh admin / lệnh dev của az_farm: Command — az_farm.

Cài đặt

Trong server.cfg, ensure az_farm phải đứng sau ensure az_core. Lần chạy đầu az_farm tự tạo bảng az_farm_player, az_farm_placed, az_farm_log.

Cấu hình sửa trên az-tool (lưu ở bảng az_config, áp ngay không cần restart, trừ khi đổi tên lệnh):

KhoáNội dungMặc định trong code
farmItems (tên / ảnh / mô tả), Prices (giá NPC + giá người chơi), Settings (gồm bón phân, quầy hàng stall*), StallUnlocks, cây trồng, vật nuôi, cấp nghề (Levels), cấp kho (CapacityLevels), trang trí, máy, công thức, vật tưconfig/farm.lua
farmWorldConfig.World: tên lệnh, toạ độ farm, bucket, trang trí, trồng trọt, máy, quầy hàng, prop tương tác (Interact), trang trại của tôi (Profile)config.lua

NUI của az_farm gọi server qua ApiAction (RegisterApiAction): POST <az-api>/api/res/az_farm/<action>, header Authorization: Bearer <token phiên NUI>. Token này az_core cấp riêng cho từng người chơi (xem az-api), không phải token GM. az-api lỗi thì NUI tự chuyển sang socket rồi NUI callback, cả 3 đường chạy cùng 1 handler. Action: storage.get, storage.upgrade, level.get, decor.shop, decor.inventory, decor.buy, machine.view, machine.craft, machine.collect, machine.unlock, machine.close, market.bootstrap, market.inventory, market.stall, market.board, market.boardBuy, market.visit, market.buy, market.create, market.remove, market.claim, market.claimAll, market.expand, profile.get, profile.rename, profile.friend, profile.visit. Kết quả: { ok = true, data } hoặc { ok = false, error = '<mã>', message = '<tiếng Việt>' }.

curl -X POST -H "Authorization: Bearer CHUOI_BI_MAT" -H "Content-Type: application/json" -d "{}" http://127.0.0.1:30126/api/res/az_farm/storage.get

Quy ước

  • src = server id. id = id nhân vật (exports.az_core:GetPlayer(src).id, cột az_users.id). Hàm ...ById dùng được cả khi người chơi offline (nạp từ DB).
  • Hàm sửa dữ liệu trả 2 giá trị ok, err: xong thì true, lỗi thì false, '<mã lỗi>'. Mã hay gặp: not_loaded (chưa vào nhân vật), invalid_id_card (id sai), invalid_count, invalid_item (không phải sản phẩm trong khoá farm), not_enough_space, not_enough_item.
  • Hàm ghi (chờ DB) có thể phải nạp dữ liệu từ DB ở lần gọi đầu, các lần sau lấy cache. Lua: gọi trong thread, event handler hoặc callback. JS: luôn await.
  • Một số hàm (chờ DB) ném lỗi khi DB lỗi, kho đang bị khoá quá 15s, hoặc (ở vài bản ...ById) id không phải số nguyên dương. Mỗi hàm có ghi rõ; cần chắc thì bọc pcall (Lua) / try (JS).
  • JS: hàm Lua trả nhiều giá trị thì JS nhận mảng, trả 1 giá trị thì nhận đúng giá trị đó (vd AddFarmItem xong trả true, lỗi trả [false, 'not_enough_space']). Nên chuẩn hoá: const arr = (r) => (Array.isArray(r) ? r : [r]);
  • Kho nông sản là kho riêng của az_farm, không nằm trong túi đồ az_core. Mỗi món chiếm 1 đơn vị sức chứa.
  • Sửa kho / EXP / cấp thì az_farm ghi DB ngay, tự đẩy cập nhật xuống NUI và client của chủ farm (nếu online), rồi bắn event server khoảng 100ms sau.

Nhóm export: Kho nông sản (OpenStorage → GetStorageById), Cấp nghề & EXP (GetFarmState → SetJobLevelById), Vào / rời farm (VisitFarm → GetFarmViewers), Prop tương tác (GetInteractConfig, IsNearFarmProp), Trang trại của tôi (OpenProfile, GetFarmName), Trang trí (OpenDecorShop → GetPlacedProps), Cấu hình (GetFarmData → GetWorldConfig), Quầy hàng (OpenMarket → GetMarketItem).

Không có cấp trang trại. Cấp nghề (từ EXP) chỉ mở khoá cây trồng, vật nuôi, công thức mới. Kho người chơi tự nâng bằng nguyên liệu (CapacityLevels). Trang trí không khoá theo cấp.

Ô đất (trang trí loại land, cần ít nhất 1 món đang bật trong Decors): không bán, chỉ tặng. Số ô = tổng Levels[].land các cấp đã đạt (cấp 1 = số ô lúc mới vào), tối đa Settings.landMax. Ai thiếu được tự bù khi mở cửa hàng / kho trang trí. Sửa trên az-tool (khoá farm → Cấp nghề, trần ở Cài đặt).

Khu đặt và lưới: prop chỉ đặt được trong vùng poly farmWorld → Decor.Area (Points ≥ 3 điểm { x, y, z }, Thickness = độ dày theo trục z quanh z trung bình các điểm). Lấy vùng bằng /tancam (chế độ poly) rồi dán vào ô “Dán zone” ở az-tool. Cả vùng phủ 1 lưới chung Decor.Grid (Cell mặc định 1,25 m, Heading = góc xoay lưới, 0 = thẳng trục X / Y). Ô hợp lệ = ô nằm trọn trong vùng. Khi đặt / di chuyển prop, trình trang trí vẽ sẵn các ô quanh prop (bán kính 6 m) và viền vùng. Ô đất (land) tự bám tâm 1 ô hợp lệ, hướng theo lưới, mỗi ô 1 đất. Đồ trang trí khác đặt tự do, bật “Khớp lưới” thì bám nửa ô. Số ô đất tối đa = min(Settings.landMax, số ô hợp lệ). Server kiểm: prop nằm trong vùng (cả z), ô đất đúng ô hợp lệ và chưa có đất. Đổi Points / Cell / Heading khi đã có đất thì đất cũ không tự dời: chặn ô chứa tâm của nó, dời đất đó thì bám vào ô mới.

OpenStorage

Kho nông sản. Mở NUI kho nông sản cho người chơi (như lệnh /khonongsan). Không kiểm người chơi đang đứng ở đâu: resource gọi tự kiểm.

local result = exports.az_farm:OpenStorage(src)
const result = exports.az_farm.OpenStorage(src)
  • src: number — server id người chơi

Trả về: boolean, string? — true; false, "not_loaded" khi chưa vào nhân vật

Ví dụ

if not exports.az_farm:OpenStorage(src) then
  exports.az_core:Notify(src, 'Chưa vào nhân vật', 'error')
end
if (exports.az_farm.OpenStorage(src) !== true) {
  exports.az_core.Notify(src, 'Chưa vào nhân vật', 'error');
}

GetStorage

Toàn bộ kho nông sản (chờ DB). Ném lỗi khi DB lỗi / kho bị khoá quá 15s.

local result = exports.az_farm:GetStorage(src)
const result = exports.az_farm.GetStorage(src)
  • src: number — server id người chơi

Trả về: table | nil — { capLevel, maxCapLevel, capacity, maxCapacity, used, minSlots, items, upgrade? }. items = mảng { name, label, category, level, count } (có cả sản phẩm đã mở khoá mà đang có 0). upgrade = { level, amount, materials } của cấp kho kế tiếp (người chơi tự nâng bằng nguyên liệu túi đồ, không khoá theo cấp nghề), không có khi kho đã tối đa. nil khi chưa vào nhân vật

Ví dụ

local st = exports.az_farm:GetStorage(src)
if st then print(('kho %d/%d'):format(st.used, st.capacity)) end
const st = await exports.az_farm.GetStorage(src);
if (st) console.log(`kho ${st.used}/${st.capacity}`);

AddFarmItem

Thêm sản phẩm vào kho (chờ DB). Ghi DB ngay, đẩy cập nhật xuống NUI kho và bắn az_farm:storageChanged. Ném lỗi khi DB lỗi / kho bị khoá quá 15s.

local result = exports.az_farm:AddFarmItem(src, name, count, force)
const result = exports.az_farm.AddFarmItem(src, name, count, force)
  • src: number — server id người chơi
  • name: string — tên sản phẩm (cây trồng, sản phẩm vật nuôi, công thức) trong khoá farm, vd lua_mi
  • count: number — số nguyên ≥ 1
  • force?: boolean — true = vượt sức chứa vẫn thêm (chỉ bỏ qua sức chứa, tên vẫn phải là sản phẩm hợp lệ)

Trả về: boolean, string? — true; false, err với err = not_loaded, invalid_count, invalid_item, not_enough_space

Ví dụ

local ok, err = exports.az_farm:AddFarmItem(src, 'lua_mi', 10)
if not ok then
  exports.az_core:Notify(src, err == 'not_enough_space' and 'Kho nông sản đầy' or 'Không thêm được', 'error')
end
const arr = (r) => (Array.isArray(r) ? r : [r]);
const [ok, err] = arr(await exports.az_farm.AddFarmItem(src, 'lua_mi', 10));
if (!ok) exports.az_core.Notify(src, err === 'not_enough_space' ? 'Kho nông sản đầy' : 'Không thêm được', 'error');

Event server

az_farm bắn bằng TriggerEvent (chỉ server). Resource khác nghe bằng AddEventHandler ở server, không dùng RegisterNetEvent (client không gửi được các event này). owner = id nhân vật chủ farm / chủ kho. Chủ farm có thể đang offline (khi resource khác sửa bằng hàm ...ById). Event của kho / EXP / cấp gom lại rồi bắn sau khoảng 100ms: storageChanged trước, rồi các event còn lại theo thứ tự xảy ra.

EventTham sốKhi nào
az_farm:farmEnteredsrc, owner, bucketNgười chơi vào farm (lệnh, EnterFarm). bucket = routing bucket của farm
az_farm:farmLeftsrc, ownerRời farm, hoặc thoát game khi đang ở trong farm. Không bắn khi az_farm stop
az_farm:storageChangedowner, name, delta, count1 sản phẩm trong kho đổi. delta cộng dồn trong 100ms (âm = bớt), count = số đang có
az_farm:expChangedowner, exp, jobLevel, addedEXP nghề đổi. exp = tổng EXP, added = số thực cộng
az_farm:jobLevelUpowner, jobLevelLên cấp nghề
az_farm:storageUpgradedowner, capLevel, capacityNâng cấp kho. capacity = sức chứa mới

AddEventHandler('az_farm:jobLevelUp', function(owner, jobLevel)
  if jobLevel == 10 then
    print(('nhân vật %d đạt cấp nghề nông 10'):format(owner))
  end
end)
 
AddEventHandler('az_farm:farmEntered', function(src, owner, bucket)
  print(('%d vào farm của %d (bucket %d)'):format(src, owner, bucket))
end)
on('az_farm:jobLevelUp', (owner, jobLevel) => {
  if (jobLevel === 10) console.log(`nhân vật ${owner} đạt cấp nghề nông 10`);

on('az_farm:farmEntered', (src, owner, bucket) => {
