API (exports)

Mọi hàm az_core mở cho resource khác, chia theo tính năng. Mỗi tính năng có trang Client và / hoặc Server. Mỗi hàm ghi chữ ký Lua + JS, tham số, giá trị trả về và ví dụ.

Mới bắt đầu: đọc Dùng core từ resource khác trước (fxmanifest, đăng ký lại khi core restart, lưu ý Lua ↔ JS).

Quy ước

LuaJS
Gọi exportexports.az_core:Ten(...)exports.az_core.Ten(...)
Hàm trả Promisegọi trong CreateThread / event handler / callback — tự chờawait
Bắt lỗipcall(function() ... end)try / catch
Không có giá trịnilnull / undefined
  • Tham số có dấu ? là không bắt buộc. Lua truyền nil ở giữa thì JS nhận null (không dùng giá trị mặc định) — truyền giá trị thật.
  • Hàm server nhận src (server id). Object Player không đi qua exports được.
  • Client không tự sửa tiền / đồ / job. Client gọi callback lên server của resource mình, server kiểm rồi mới gọi export.
