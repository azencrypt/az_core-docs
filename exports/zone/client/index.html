Zone (vùng) — Client

Vùng đa giác / hộp / cầu kiểu ox_lib: báo khi nhân vật vào, ra, đang ở trong. Kiểm tra mỗi 250 ms, chỉ chạy tick mỗi frame khi có zone debug hoặc callback inside.

Trường của zone

Tên trường giống ox_lib zones, chép code ox sang chỉ cần đổi lời gọi.

TrườngKiểuMặc địnhDùng cho
pointsvector3[] (≥ 3 đỉnh)—poly
thicknessnumber4poly — cao tổng, chia đôi quanh z trung bình các đỉnh
coordsvector3—box (tâm hộp), sphere (tâm cầu)
sizevector3vec3(2, 2, 2)box
rotationnumber (độ)0box, xoay quanh trục z
radiusnumber2sphere
minZ / maxZnumbertính tự độngpoly, box — ghi đè chiều cao
namestring—tên để log / debug
onEnter / onExitfunction(self)—gọi khi nhân vật vào / ra (kiểm 4 lần/giây)
insidefunction(self)—gọi mỗi frame khi đang ở trong
debugbooleanfalsevẽ tường zone (trong 150 m)
debugColourvec4(r, g, b, a)đỏ 255, 42, 24, 70màu khi debug
data và trường tự thêmbất kỳ—trả lại trong self

Toạ độ nhận cả vector3 (Lua), bảng { x, y, z } và mảng [x, y, z]. type ('poly' | 'box' | 'sphere') chỉ cần khi gọi AddZone; bỏ trống thì tự đoán theo points / radius / size.

self trong callback: { id, name, type, resource, coords, center, insideZone, data, ...trường tự thêm } (coords = center = tâm zone). Ví dụ AddBoxZone({ ..., shop = 'ltd' }) thì self.shop == 'ltd'.

Khác ox_lib

ox_libaz_core
local z = lib.zones.poly({...}) trả objectlocal id = exports.az_core:AddPolyZone({...}) trả id (số), sai dữ liệu trả nil + log lỗi
z:remove()exports.az_core:RemoveZone(id) (đang ở trong thì gọi onExit trước)
z:contains(p)exports.az_core:IsInZone(id, p)
z:setDebug(true, colour)exports.az_core:SetZoneDebug(id, true, colour)
lib.zones.getCurrentZones()exports.az_core:GetCurrentZones()
lib.zones.getAllZones()exports.az_core:GetAllZones()
gán z.onEnter = fn sau khi tạotruyền onEnter ngay lúc tạo (muốn đổi thì RemoveZone rồi tạo lại)

Zone thuộc resource đã tạo: resource đó stop là zone tự xoá. Restart az_core thì mọi zone mất — tạo lại trong OnCore(...) (Lua mẫu) hoặc khi nghe onClientResourceStart('az_core').

Lấy toạ độ bằng /tancam

Lệnh admin /tancam (bay cam tự do) có sẵn công cụ vẽ zone, chép ra clipboard để dán thẳng vào code:

PhímViệc
1 / 2 / 3 / 4Camera / đa giác / hộp / cầu (hoặc /tancam poly, /tancam box, /tancam sphere)
SpaceThêm đỉnh (poly) / đặt tâm (box, sphere) tại chỗ đang nhìn
ZBỏ đỉnh cuối (poly)
Lăn chuộtĐộ dày (poly) / xoay (box) / bán kính (sphere)
← → ↑ ↓ PgUp PgDnDài / rộng / cao của hộp
Shift / AltBước ×4 / ×0.2
EnterChép zone
X / CChép điểm đang nhìn / toạ độ nhân vật (vec4 có heading)
MMở menu chuột: chọn định dạng, đặt tên, sửa từng số, xoá đỉnh, xem trước code

Zone vẽ màu đỏ, chuyển xanh khi nhân vật hoặc điểm nhìn nằm trong. Định dạng chép (nhớ cho lần sau): Lua az_core (exports.az_core:AddPolyZone({...})), JS az_core, JSON, ox_lib (lib.zones.poly({...})).

AddPolyZone

Tạo zone đa giác (lăng trụ đứng). Đa giác lõm vẫn đúng.

local result = exports.az_core:AddPolyZone(def)
const result = exports.az_core.AddPolyZone(def)
  • def: table — định nghĩa zone (xem bảng trường bên dưới)

Trả về: number | nil — id zone, nil nếu dữ liệu sai

Ví dụ

local zoneId = exports.az_core:AddPolyZone({
    name = 'bai_xe',
    points = {
        vec3(215.12, -810.40, 30.73),
        vec3(230.50, -805.20, 30.60),
        vec3(238.90, -822.75, 30.20),
        vec3(221.33, -830.10, 30.40),
    },
    thickness = 4.0,
    debug = true,
    onEnter = function(self)
        print('vào', self.name, self.id)
    end,
    onExit = function(self)
        print('ra', self.name)
    end,
})
const zoneId = exports.az_core.AddPolyZone({
  name: 'bai_xe',
  points: [
    { x: 215.12, y: -810.4, z: 30.73 },
    { x: 230.5, y: -805.2, z: 30.6 },
    { x: 238.9, y: -822.75, z: 30.2 },
  ],
  thickness: 4,
  onEnter: (self) => console.log('vào', self.name),
  onExit: (self) => console.log('ra', self.name),
});

AddBoxZone

Tạo zone hộp: coords là tâm hộp, size = dài (x) × rộng (y) × cao (z), rotation độ quanh trục z.

local result = exports.az_core:AddBoxZone(def)
const result = exports.az_core.AddBoxZone(def)
  • def: table — định nghĩa zone (xem bảng trường bên dưới)

Trả về: number | nil

Ví dụ

local zoneId = exports.az_core:AddBoxZone({
    coords = vec3(225.40, -815.20, 32.10),
    size = vec3(8.0, 5.0, 3.0),
    rotation = 70.0,
    shop = 'ltd_1',
    inside = function(self)
        if IsControlJustPressed(0, 38) then
            TriggerServerEvent('myres:open', self.shop)
        end
    end,
})
const zoneId = exports.az_core.AddBoxZone({
  coords: { x: 225.4, y: -815.2, z: 32.1 },
  size: { x: 8, y: 5, z: 3 },
  rotation: 70,
  shop: 'ltd_1',
  inside: (self) => {
    if (IsControlJustPressed(0, 38)) emitNet('myres:open', self.shop);
  },
});

AddSphereZone

Tạo zone cầu (khoảng cách 3D tới coords ≤ radius).

local result = exports.az_core:AddSphereZone(def)
const result = exports.az_core.AddSphereZone(def)
  • def: table — định nghĩa zone (xem bảng trường bên dưới)

Trả về: number | nil

Ví dụ

local zoneId = exports.az_core:AddSphereZone({
    coords = vec3(225.40, -815.20, 30.60),
    radius = 6.5,
    debug = true,
    debugColour = vec4(0, 150, 255, 60),
})
const zoneId = exports.az_core.AddSphereZone({ coords: [225.4, -815.2, 30.6], radius: 6.5 });

AddZone

Tạo zone bất kỳ loại nào — tiện khi đọc danh sách zone từ config.

local result = exports.az_core:AddZone(def)
const result = exports.az_core.AddZone(def)
  • def: table — như trên, thêm type = 'poly' | 'box' | 'sphere' (bỏ trống thì tự đoán)

Trả về: number | nil

Ví dụ

for _, z in ipairs(Config.Zones) do
    exports.az_core:AddZone(z)
end
for (const z of Config.Zones) exports.az_core.AddZone(z);

RemoveZone

Xoá zone. Nhân vật đang ở trong thì onExit được gọi trước khi xoá.

local result = exports.az_core:RemoveZone(id)
const result = exports.az_core.RemoveZone(id)
  • id: number — id do AddZone / AddPolyZone / … trả về

Trả về: boolean — false nếu không có id này

Ví dụ

exports.az_core:RemoveZone(zoneId)
exports.az_core.RemoveZone(zoneId);

IsInZone

Điểm có nằm trong zone không (tương đương zone:contains(point) của ox_lib).

local result = exports.az_core:IsInZone(id, coords?)
const result = exports.az_core.IsInZone(id, coords?)
  • id: number — id do AddZone / AddPolyZone / … trả về
  • coords?: vector3 | {x,y,z} — bỏ trống = vị trí nhân vật mình

Trả về: boolean

Ví dụ

if exports.az_core:IsInZone(zoneId) then print('đang ở trong') end
print(exports.az_core:IsInZone(zoneId, GetEntityCoords(vehicle)))
if (exports.az_core.IsInZone(zoneId)) console.log('đang ở trong');

GetZone

Thông tin zone, giống self trong callback: { id, name, type, resource, coords, center, insideZone, data, ... }.

local result = exports.az_core:GetZone(id)
const result = exports.az_core.GetZone(id)
  • id: number — id do AddZone / AddPolyZone / … trả về

Trả về: table | nil

GetCurrentZones

Các zone nhân vật đang ở trong (mọi resource), mỗi phần tử dạng self.

local result = exports.az_core:GetCurrentZones()
const result = exports.az_core.GetCurrentZones()

Trả về: table[]

GetAllZones

Mọi zone đang có (mọi resource).

local result = exports.az_core:GetAllZones()
const result = exports.az_core.GetAllZones()

Trả về: table[]

GetZonesAt

Id các zone chứa điểm này (tính ngay, không chờ vòng kiểm 250 ms).

local result = exports.az_core:GetZonesAt(coords?)
const result = exports.az_core.GetZonesAt(coords?)
  • coords?: vector3 | {x,y,z} — bỏ trống = vị trí nhân vật mình

Trả về: number[]

SetZoneDebug

Bật / tắt vẽ zone.

local result = exports.az_core:SetZoneDebug(id, on, colour?)
const result = exports.az_core.SetZoneDebug(id, on, colour?)
  • id: number — id do AddZone / AddPolyZone / … trả về
  • on: boolean
  • colour?: vec4(r, g, b, a) — đổi màu vẽ

Trả về: boolean

Ví dụ

exports.az_core:SetZoneDebug(zoneId, true, vec4(255, 0, 0, 100))
exports.az_core.SetZoneDebug(zoneId, true, [255, 0, 0, 100]);

IsPointInZone

Kiểm 1 lần với định nghĩa zone, không đăng ký zone (không có callback). Dữ liệu sai trả false.

local result = exports.az_core:IsPointInZone(def, coords)
const result = exports.az_core.IsPointInZone(def, coords)
  • def: table — định nghĩa zone (xem bảng trường bên dưới)
  • coords: vector3 | {x,y,z}

Trả về: boolean

Ví dụ

local inside = exports.az_core:IsPointInZone({ coords = vec3(0.0, 0.0, 70.0), radius = 5.0 }, GetEntityCoords(PlayerPedId()))
const inside = exports.az_core.IsPointInZone({ coords: [0, 0, 70], radius: 5 }, GetEntityCoords(PlayerPedId()));
