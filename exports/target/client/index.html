Target (mắt tương tác) — Client

Mắt tương tác: thêm lựa chọn khi nhìn vào ped, xe, đồ vật, người chơi hoặc đứng trong zone.

Giữ Alt trái để bật mắt, nhắm vào ped / xe / đồ vật / zone có lựa chọn, bấm chuột trái để hiện con trỏ rồi chọn (chuột phải tắt con trỏ), thả Alt là đóng. Người chơi đổi phím trong Cài đặt → Phím tắt → FiveM (lệnh +az_target). Giao diện: lục giác vàng, lựa chọn xếp zigzag 7 dòng / cột.

Trường của option

TrườngKiểuGhi chú
labelstringbắt buộc, cho phép HTML
namestringđể gỡ bằng Remove*; trùng tên cùng resource thì thay
icon / iconColorstringclass Font Awesome 7 (vd fa-solid fa-car) / màu CSS
distancenumbermặc định 7
groupsstring | string[] | { [job]: gradeMin }so với job az_core của người chơi
itemsstring | string[] | { [item]: số lượng }cần tất cả (hoặc 1 nếu anyItem = true)
bonesstring | string[]chỉ hiện khi nhắm gần bone (≤ 2 m, bone gần nhất ≤ 1 m)
offset / absoluteOffset / offsetSizevector3 / boolean / numberđiểm theo tỉ lệ kích thước model (0..1), absoluteOffset = true thì là mét; bán kính mặc định 1
canInteractfunction(entity, distance, coords, name, bone)trả false/nil = ẩn
menuName / openMenustringoption thuộc menu con / bấm thì mở menu con (tự thêm nút Quay lại)
onSelectfunction(data)gọi khi bấm. Có onSelect thì bỏ qua 4 trường dưới
exportstringtên export của resource đăng ký option → gọi exports[resource][export](data)
event / serverEvent / commandstringTriggerEvent / TriggerServerEvent / ExecuteCommand

data nhận được: bản sao option (đã bỏ icon, groups, items, canInteract, onSelect, export, event, serverEvent, command) + entity, coords, distance, zone (id zone khi chọn trong zone). serverEvent gửi entity dạng netId (0 nếu không có mạng). coords là bảng { x, y, z } (Lua cần vector thì vec3(coords.x, coords.y, coords.z)).

Zone target dùng hình học zone của az_core (xem Zone), thêm trường options và drawSprite (vẽ chấm tròn khi đứng gần, mặc định bật). Box mặc định size = vec3(4, 4, 4).

Cấu hình

src/shared/target.js: DefaultHotkey (LMENU), ToggleHotkey (bấm 1 lần bật / tắt thay vì giữ), LeftClick, Debug (zone / option thử ở LSPD, chỉ để dò lỗi), DrawSprite (số chấm zone tối đa, 0 = tắt), Defaults (option có sẵn mở / đóng cửa xe, capo, cốp), DoorMaxDistance (server kiểm khoảng cách khi nhờ chủ xe mở cửa), Labels.

Lưu ý

  • Resource stop thì mọi option + zone target của resource đó tự gỡ.
  • Restart az_core thì mọi option mất: đăng ký lại khi nghe onClientResourceStart với res == 'az_core'.
  • AddTargetEntity cho entity mạng: server bật state bag hasTargetOptions, entity mất thì option tự xoá (10 giây / lần).

AddGlobalPed

Thêm option cho mọi ped (không phải người chơi).

exports.az_core:AddGlobalPed(options)
exports.az_core.AddGlobalPed(options)
  • options: Option | Option[] — xem bảng Trường của option

Ví dụ

exports.az_core:AddGlobalPed({
    {
        name = 'myres:talk',
        icon = 'fa-solid fa-comment',
        label = 'Nói chuyện',
        distance = 2.0,
        canInteract = function(entity) return not IsPedDeadOrDying(entity, true) end,
        onSelect = function(data) print('ped', data.entity) end,
    },
})
exports.az_core.AddGlobalPed([{ name: 'myres:talk', icon: 'fa-solid fa-comment', label: 'Nói chuyện', onSelect: (data) => console.log(data.entity) }]);
