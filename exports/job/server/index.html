Job & ca trực — Server

Job lưu ở player.job: name, label, grade, gradeLabel, salary, onDuty. Đổi job / ca → event az_core:jobChanged và tự chuyển room socket job:<tên>.

Hướng dẫn chi tiết: Job.

Event jobChanged

AddEventHandler('az_core:jobChanged', function(src, job, oldJob)
  if job.name == 'police' and job.onDuty then print(src, 'vào ca cảnh sát') end
end)
on('az_core:jobChanged', (src, job, oldJob) => {
  if (job.name === 'police' && job.onDuty) console.log(src, 'vào ca cảnh sát');
});

GetJob

Job hiện tại: { name, label, grade, gradeLabel, salary, onDuty }.

local result = exports.az_core:GetJob(src)
const result = exports.az_core.GetJob(src)
  • src: number — server id người chơi

Trả về: table | nil

Ví dụ

local job = exports.az_core:GetJob(source)
if job.name == 'police' and job.onDuty and job.grade >= 2 then
  -- ...
end
const job = exports.az_core.GetJob(source);
if (job.name === 'police' && job.onDuty && job.grade >= 2) {
  // ...
}

SetJob

Đổi job / bậc. Đổi sang job khác thì tự hết ca.

local result = exports.az_core:SetJob(src, name, grade)
const result = exports.az_core.SetJob(src, name, grade)
  • src: number — server id người chơi
  • name: string — phải có trong Config.Jobs
  • grade?: number — mặc định 0

Trả về: boolean

Ví dụ

exports.az_core:SetJob(target, 'ambulance', 1)
exports.az_core.SetJob(target, 'ambulance', 1);

SetDuty

Vào / hết ca.

local result = exports.az_core:SetDuty(src, on)
const result = exports.az_core.SetDuty(src, on)
  • src: number — server id người chơi
  • on: boolean

Trả về: boolean | nil — trạng thái mới; nil = không có job

ToggleDuty

Đảo trạng thái ca trực.

local result = exports.az_core:ToggleDuty(src)
const result = exports.az_core.ToggleDuty(src)
  • src: number — server id người chơi

Trả về: boolean | nil — trạng thái mới; nil = không có job

Ví dụ

RegisterNetEvent('myres:duty', function()
  local on = exports.az_core:ToggleDuty(source)
  if on ~= nil then exports.az_core:Notify(source, on and 'Vào ca' or 'Hết ca', 'info') end
end)
onNet('myres:duty', () => {
  const src = source;
  const on = exports.az_core.ToggleDuty(src);
  if (on != null) exports.az_core.Notify(src, on ? 'Vào ca' : 'Hết ca', 'info');
});

IsOnDuty

Đang trong ca không.

local result = exports.az_core:IsOnDuty(src)
const result = exports.az_core.IsOnDuty(src)
  • src: number — server id người chơi

Trả về: boolean

Apply

Nộp hồ sơ vào job nhà nước có bảng quản lý trong core (vd ambulance; Công an nộp ở NPC lễ tân của mp_police).

local result = exports.az_core:Apply(src, job)
const result = await exports.az_core.Apply(src, job)
  • src: number — server id người chơi
  • job: string

Trả về: Promise → true | string — true hoặc mã lỗi

GetBalance

Số dư quỹ ngành (job có bảng quản lý trong core; quỹ Công an do mp_police giữ).

local result = exports.az_core:GetBalance(job)
const result = exports.az_core.GetBalance(job)
  • job: string

Trả về: number

AddFund

Cộng / trừ quỹ ngành.

local result = exports.az_core:AddFund(job, amount, note, ref)
const result = exports.az_core.AddFund(job, amount, note, ref)
  • job: string — job có bảng quản lý trong core
  • amount: number — âm = trừ quỹ
  • note?: string — mặc định = tên resource gọi
  • ref?: string — mã giao dịch duy nhất của resource gọi; gọi lại cùng ref thì không cộng lần 2 (nên truyền khi có thể gọi lại sau timeout)

Trả về: number | nil — số dư mới; nil = lỗi (vd quỹ không đủ, ref dài quá, job không có bảng quản lý)

Ví dụ

exports.az_core:AddFund('ambulance', 500, 'Phí cấp cứu', 'ems:' .. id)
exports.az_core.AddFund('ambulance', 500, 'Phí cấp cứu', 'ems:' + id);

SetJobByIdCard

Đổi job theo char id, người chơi online hay offline đều được (offline sửa thẳng az_users). Online thì bắn az_core:jobChanged như SetJob.

local result = exports.az_core:SetJobByIdCard(idCard, name, grade, from)
const result = await exports.az_core.SetJobByIdCard(idCard, name, grade, from)
  • idCard: number — char id (az_users.id)
  • name?: string — nil = job mặc định (Config.DefaultJob)
  • grade?: number — mặc định 0
  • from?: string — chỉ đổi khi người đó đang ở job này

Trả về: Promise → 'online' | 'offline' | false — 'online' / 'offline' = đã đổi; false = sai tham số, không tìm thấy hoặc không đúng from

Ví dụ

-- cho thôi việc (về job mặc định), chỉ khi người đó còn là police
local r = exports.az_core:SetJobByIdCard(charId, nil, nil, 'police')
const r = await exports.az_core.SetJobByIdCard(charId, null, null, 'police');

SetGrades

Đổi tên cấp + lương / giờ lúc chạy: HUD, GetJob thấy ngay. Resource gọi dừng thì về tên / lương gốc trong Config.Jobs.

local result = exports.az_core:SetGrades(job, grades)
const result = exports.az_core.SetGrades(job, grades)
  • job: string — job không có bảng quản lý trong core
  • grades: table — { ['0'] = { label, salary }, ... } (khoá là chuỗi). Cấp không có trong bảng thì về tên / lương gốc

Trả về: boolean

Ví dụ

exports.az_core:SetGrades('police', { ['1'] = { label = 'Sĩ quan tuần tra', salary = 800 } })
exports.az_core.SetGrades('police', { 1: { label: 'Sĩ quan tuần tra', salary: 800 } });

SetPaycheck

Bật / tắt lương tự động mỗi Config.PaycheckInterval của 1 job (resource tự phát lương theo giờ trực). Resource gọi dừng thì bật lại.

local result = exports.az_core:SetPaycheck(job, on)
const result = exports.az_core.SetPaycheck(job, on)
  • job: string
  • on: boolean — false = không trả lương tự động cho job này

Trả về: boolean

Payroll

Cộng lương vào GO Bank (online cộng ngay, offline nhận lúc vào game) kèm tin nhắn phiếu lương. Quỹ và giờ trực do resource gọi tự giữ.

local result = exports.az_core:Payroll(list, meta)
const result = await exports.az_core.Payroll(list, meta)
  • list: table — {{ idCard, name, gradeLabel, rate, seconds, amount }}, tối đa 200 người, không trùng
  • meta: table — { title, mult, by, byGrade, from? }; mult là 1 / 1.5 / 2 / 3, from = lần phát trước (ms)

Trả về: Promise → { paid, failed, skipped } | false — paid = {{ idCard, amount, online }}; failed = id offline ghi lỗi, chưa nhận (nên hoàn quỹ); skipped = id chưa có tài khoản GO Bank; false = tham số sai
