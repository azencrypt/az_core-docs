Event phía client: az_core:playerDied (info), az_core:playerRevived (info). Người khác đang gục: state bag downed.

AddEventHandler('az_core:playerDied', function(info) print('bị hạ bởi', info.killer) end)
local downed = Player(GetPlayerServerId(otherPlayer)).state.downed
on('az_core:playerDied', (info) => console.log('bị hạ bởi', info.killer));
const downed = Player(GetPlayerServerId(otherPlayer)).state.downed;

IsDead

Mình đang gục / chết. Có resource giữ SetDeathProvider thì đọc state bag isDead của mình.

local result = exports.az_core:IsDead()
const result = exports.az_core.IsDead()

Trả về: boolean

Ví dụ

if exports.az_core:IsDead() then return end
if (exports.az_core.IsDead()) return;

Resurrect

Hồi sinh ped của mình bằng NetworkResurrectLocalPlayer; nếu game tạo ped mới thì core áp lại ngoại hình + đồ đang mặc. Dành cho resource giữ SetDeathProvider (mp_ambulance) tự đặt người gục / bất tỉnh. Trả ped mới.

local result = exports.az_core:Resurrect(x, y, z, heading)
const result = exports.az_core.Resurrect(x, y, z, heading)
  • x?: number — bỏ trống = chỗ đang đứng
  • y?: number
  • z?: number
  • heading?: number

Trả về: number

Ví dụ

local ped = exports.az_core:Resurrect()
