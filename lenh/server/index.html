CommandServer (lệnh chat)

Command — Server

Lệnh chat (/lenh) core đăng ký phía server bằng Commands.register / export RegisterCommand. Mỗi lệnh có nhóm quyền tối thiểu. Người chơi chỉ thấy gợi ý những lệnh đủ quyền.

NhómCấpĐặt bằng
user0mặc định (Config.DefaultGroup)
mod1/setgroup [id] mod
admin2/setgroup [id] admin
superadmin3/setgroup [id] superadmin

Cấp quyền bằng server.cfg (ACE)

Ngoài /setgroup (lưu DB), có thể cấp nhóm trong server.cfg giống ESX / txAdmin. Core đọc quyền ACE az.group.<tên nhóm>:

# cho mỗi nhóm FiveM quyền az tương ứng
add_ace group.admin az.group.admin allow
add_ace group.superadmin az.group.superadmin allow

# gán người chơi vào nhóm (license lấy trong txAdmin / F8)
add_principal identifier.license:XXXXXXXXXXXXXXXX group.admin
  • Nhóm thực tế là nhóm cao hơn giữa DB và ACE. ACE không ghi vào DB.
  • Xoá dòng add_principal thì người đó tự về nhóm trong DB ở lần vào sau.
  • /setgroup không hạ được người đang có nhóm cao hơn từ ACE.

Cấp lấy từ Config.Groups. Nhóm cao hơn dùng được lệnh của nhóm thấp hơn. Hầu hết lệnh chạy được từ console server (gõ không có /). Các lệnh không chạy từ console được (cần người chơi đứng trong game): money, job, vip, tp, tpm, goto, bring, noclip, car, dv, givekey, removekey, removekeys, dmvpos, dmvroute, minigame. Lệnh có (id) “bỏ trống = bản thân” thì từ console phải truyền id.

Tham số trong [ngoặc vuông] là bắt buộc, (ngoặc tròn) là tuỳ chọn. Trong cột “Tham số”, id là server id của người chơi đang online.

Thêm lệnh mới

Dùng export RegisterCommand (chi tiết: API → Callback & Command). Handler nhận một object ctx: src, player, args, raw, reply, isConsole.

exports.az_core:RegisterCommand('heal', 'admin', function(ctx)
  local target = tonumber(ctx.args[1]) or ctx.src
  if ctx.isConsole and target == 0 then return ctx.reply('Dùng: heal [id]') end
  TriggerClientEvent('myres:heal', target)
  ctx.reply(('Đã hồi máu cho %d'):format(target))
end, {
  help = 'Hồi máu',
  params = { { name = 'id', help = 'ID player (bỏ trống = bản thân)' } },
})
exports.az_core.RegisterCommand('heal', 'admin', (ctx) => {
  const target = Number(ctx.args[0]) || ctx.src;
  if (ctx.isConsole && target === 0) return ctx.reply('Dùng: heal [id]');
  emitNet('myres:heal', target);
  ctx.reply(`Đã hồi máu cho ${target}`);
}, {
  help: 'Hồi máu',
  params: [{ name: 'id', help: 'ID player (bỏ trống = bản thân)' }],
});
  • Lua: ctx.args[1] là tham số đầu (mảng JS chuyển sang Lua bắt đầu từ 1).
  • allowConsole = false trong opts để chặn chạy từ console.
  • Lệnh đăng ký từ resource khác vẫn kiểm tra quyền theo nhóm của core.
